# 화면 영역 이름

화면 위치는 **바탕색으로 구분한 세 영역**의 이름으로 부른다. 지시는 "영역 > 위치"로 쓴다.
예: "상단 영역 오른쪽 끝의 스크린샷 버튼", "메인 영역 > 맨 아래 줄 > 범례", "사이드 영역 > 맨 아래 > Basis".

| 영역 | 바탕색 | 화면 위치 | 코드 |
|---|---|---|---|
| **상단 영역** | `#1a1a1a` (어두운 중립 회색) | 맨 위. 로고 줄, Home · Map · Graph · Custom 메뉴 줄(글자 앞에 설정창과 같은 아이콘), 오른쪽 끝 버튼(스크린샷·전체 화면·설정) | `NavBar`, `NavSubBar` |
| **메인 영역** | `#0a0a0a` (거의 검정) | 가운데. 페이지마다 다르다(Map은 히트맵, Graph는 막대 그래프, Custom은 표). 화면 스크린샷은 메인 영역만 찍는다. | `src/pages/MapPage.tsx`, `GroupPage.tsx`, `CustomPage.tsx` |
| **사이드 영역** (설정창·정보 패널) | `#2a2a2a` (중립 회색) | 옆에 붙은 설정·정보 영역. 이동 버튼으로 왼쪽과 오른쪽을 바꿀 수 있고 접을 수도 있다. | `SettingsPanel`, `PageInfoPanel` |

- 영역을 구분할 때는 바탕색을 기준으로 한다. 색이 같은 줄은 같은 영역이다.
- 앱의 기본 스크롤바는 공통 규격(폭 6px, 트랙 흰색 10%, 손잡이 흰색 35%, 3px 둥근 모서리)을 쓴다. 표·팝업·본문을 포함한 스크롤 영역에 같은 색과 모양을 적용한다. 의도적으로 스크롤바를 숨기는 `scrollbar-hide` 영역과, 넘칠 때만 별도 트랙을 그리는 `ScrollArea`는 예외다. 메인 본문 스크롤에는 `page-main-scroll` 클래스를 쓴다. 업종 제외·배너 설정창 목록은 `ScrollArea`를 쓰며, 내용이 표시 높이를 넘을 때만 스크롤 트랙과 손잡이를 보이고 드래그·트랙 클릭으로 이동할 수 있게 한다. 배너·메시지·정보·프로필 페이지는 외곽선 안에서 제목·요약·구분선을 포함한 전체가 본문과 함께 스크롤된다(`PageMainFrame`의 `heading`). 예전에는 제목·요약·구분선을 고정하고 구분선 아래만 스크롤했고, 일부 페이지에서 되살릴 수 있게 `fixHeading` 옵션으로 남겨 두었다.
- 정보 페이지(이용약관·개인정보처리방침·데이터·문의)는 `InfoDocument` 공통 제목·요약·시행일·구획 제목 양식을 쓴다. 번호 배지가 있는 구획 제목에는 청록 막대를 겹쳐 쓰지 않는다. 긴 설명은 목록으로 나누고, 출처·항목·보관 기간처럼 비교할 정보는 공통 테두리와 패널 배경의 행·카드로 정리한다. 강조는 기존 청록·회색 UI 토큰만 사용하고, 각 페이지의 오른쪽 Info 패널에는 해당 페이지 설명을 표시한다.
- 배너·메시지 페이지도 정보 페이지와 같은 `PageMainFrame` 외곽선과 24px 안쪽 여백, `max-w-4xl` 본문 폭을 사용해 제목 시작 위치를 맞춘다. 제목의 구분선까지 외곽선 안에 고정하고, 아래 콘텐츠만 내부에서 스크롤한다.
- 정보 페이지의 시행일 배지는 제목 줄 오른쪽에 놓는다. 그 아래에 설명문 한 줄과 구분선을 배치하며, 화면 폭이 부족하면 설명문은 자연스럽게 줄바꿈한다.
- 전체화면은 내부 페이지 이동 중에도 유지한다. 내부 링크는 라우터의 `Link`로 이동하고, 전체화면 버튼과 Esc 처리는 `useNativeFullscreen`에서 브라우저의 실제 상태를 구독한다.
- 프로필 페이지는 `PageMainFrame`과 `InfoPageHeading`으로 제목·요약을 구성하고 계정 정보, 닉네임 편집, 사진 관리, 계정 동작을 패널로 나눈다. 패널 배경 위의 설명·보조 문구는 대비가 약해지지 않도록 14px 본문색(`text-ui-text`)을 쓴다. 이메일 연동 아이콘, 입력 검증·오류 문구, 탈퇴 확인 동작을 유지하며 상태 문구가 나타나도 입력과 버튼이 갑자기 움직이지 않게 한다.
- 인포·프로필 사이드 패널의 설명과 안내는 공통 텍스트 그룹으로 표시한다. 글자 크기 14px, 기본 굵기, 본문색으로 한 줄씩 표시하고, 한 문구 또는 여러 문구 전체를 하나의 180px 높이 안에서 가로·세로 가운데 정렬한다. 항목 사이 구분선은 넣지 않고, 긴 문구는 한 줄 말줄임으로 표시한다.
- 홈·맵·그룹·커스텀·운영 페이지는 메인·설정창의 바깥 좌우 여백과 두 영역 사이 간격을 각각 4px로 맞춘다. 설정창을 왼쪽으로 옮겨도 같으며, 접으면 사이 간격을 없앤다. 여백은 `main-settings-row`에서 관리하고 툴바·본문·아래 줄에 중복으로 넣지 않는다.
- 설정창과 정보 패널이 있는 모든 페이지는 `SettingsPanelSideToggle` 공통 이동 버튼을 쓴다. 버튼 위쪽은 Basis 상단 기준선, 아래쪽은 분류 배지 상단선에 맞춘다. Basis가 없는 어드민·정보 패널은 같은 기준에 대응하도록 패널 아래 66px에 45px 높이로 둔다. 앵커 선택자와 기본 위치·높이는 `SettingsPanelSideToggle` 한곳에서 관리하고 페이지별 예외를 추가하지 않는다. `settings-panel-on-left` 브라우저 설정을 공유하고, 이동할 때 메인 영역과 패널이 함께 자리를 바꾼다.
- **헤더**는 영역 이름이 아니다. 각 영역·표의 맨 윗줄을 가리키는 말이라 항상 앞에 붙여 쓴다: "설정창 헤더"(사이드 영역 맨 윗줄), "표 헤더"(열 머리글).
- 세 영역 밖의 것은 건드리지 않는다. 지시한 영역에서 벗어난 파일을 고쳐야 하면 먼저 알린다.
- Home 같은 페이지에는 사이드 영역이 없다.

- 메뉴 줄 하단선부터 설정창 외곽선까지의 세로 여백은 4px이며, 메인 영역과 설정창 사이의 가로 여백도 4px이다. `main-settings-row`는 메뉴 하단선까지 올라가고, 실제 메인 렌더·캡처 영역(`data-main-area`)은 그 안에서 4px 아래에 둔다. 설정창 외곽선과 메인 렌더 영역의 윗선은 같은 위치여야 한다.
- 설정창은 상단 영역 아래에서 4px 띄운다. 헤더는 윗선을 기존보다 3px 올리되 아래 구분선은 유지한다. 헤더 위아래 패딩은 각각 11.75px로 같게 두어 제목·종목 수·버튼을 세로 중간에 맞추고, 탭 메뉴와 설정 본문은 그 아래에 이어진다.
- 설정창 하단은 화면 아래에서 4px 띄운다. 하단 Basis 영역의 아래 패딩을 4px 줄여 확보하며 설정 본문 높이는 유지한다.
- 메인 툴바 배지·칩·검색창은 기본 24px에서 아래쪽으로만 2.25px 늘린 26.25px 높이다. `main-toolbar` 안의 `toolbar-badge`는 음수 아래 여백으로 윗선과 주변 배치를 유지하고, 내부 버튼은 `toolbar-badge-control`로 높이를 맞춘다.
- 설정창 선택 버튼·시가총액 범위 배지·Basis 버튼·작은 업종명 배지는 라운딩 4px로 맞춘다. 메인 툴바 분류 배지는 직각, 설정창 외곽은 6px다.
- **선택형 버튼 호버 기준**: 설정창의 기본 상태는 미선택 회색, 호버 흰색, 선택 청록색이다. 한 항목이 선택된 버튼 묶음은 선택 상태를 호버로 강조하지 않고, 선택되지 않아 상태를 바꿀 수 있는 버튼에만 `--ui-control-hover` 호버를 표시한다. 독립 실행 버튼은 선택 상태와 무관하게 활성일 때 호버를 표시하고, 비활성 버튼에는 호버를 표시하지 않는다. 설정창 세그먼트와 배너 상단 전환·기간 버튼은 페이지별 조건문 대신 `settings-choice-hover` 공통 규칙을 사용하며, 버튼에 `aria-checked` 또는 `aria-pressed` 상태를 제공한다. 청록색 선택 버튼·실행 버튼·슬라이더 손잡이·드롭박스와 시각 선택기의 꺾쇠는 청록 외곽선 없이 단색으로 표시한다. 밝은 청록 손잡이 안쪽의 꺾쇠는 진한 `--ui-surface`로 표시한다.
- **계단형 업종 단계 선택**: 업종 분류 깊이·그래프 업종 분류 단계·업종 지표 표시 단계·상위 업종 강조에 공통 적용한다. 선택 영역과 그 연결선은 선택 100%, 미선택 70%, 선택 불가 10% opacity로 표시한다. 누적 선택에서는 선택한 단계까지의 앞선 단계도 선택 상태로 본다. opacity는 단계 영역 전체(배경·단계명·연결선)에 한 번 적용한다.
- 홈의 세 항목 제목은 각 항목 왼쪽에 놓고 오른쪽으로 구분선을 잇는다. 제목 글자색은 지도 설정의 강조 색상을 따르며, 배지는 지도 대분류와 같은 흰색 18% 배경·3px 라운딩·좌우 4px 패딩을 쓴다.
- **설정 항목의 공통 구조(새 항목에도 필수 적용)**: `n) 헤더` → `- 설명 문구` → 그 아래 남은 **버튼 영역** 순서로 구성한다. 이 세 부분을 합친 한 항목의 전체 높이는 **180px**다. 버튼·슬라이더·입력창 등 조작부 묶음은 버튼 영역의 세로 중간에 둔다. 항목 사이는 공통 구분선으로 나눈다. 페이지나 기능별로 별도 프레임·고정 간격을 만들지 않고 공통 설정창 구조와 정렬 규칙을 사용한다.
- 모든 페이지 설정창의 각 항목 높이는 첫 항목을 포함해 180px로 통일한다. 각 항목 제목은 기존보다 4px 아래에 둔다. 본문 상단 여백 12px는 항목 높이와 별도로 둔다. 목록은 항목 내부에서 스크롤하고, 조작부는 제목·설명 아래 남은 공간의 세로 중간에 둔다. 홈·그룹·커스텀·어드민의 버튼·슬라이더·입력부 묶음을 제목·설명 하단과 항목 아래 구분선 사이의 세로 중간에 맞춘다(구분선은 다음 제목 12px 위). 맵도 조작부 묶음의 실제 높이를 기준으로 남은 공간을 위아래로 나누며, 항목 위치를 맞추기 위한 9.5px·7.5px 같은 고정 위 여백은 쓰지 않는다. 업종 지표 선택 줄과 예시 그림, 박스 크기 아이콘·트랙·라벨은 각각 한 묶음으로 정렬한다.
- 모든 페이지 설정창은 항목 사이와 마지막 항목 아래에 같은 구분선(흰색 12%, 1px)을 표시한다. 맵·어드민과 단일 탭 안에 항목을 쌓는 홈·그룹·커스텀에 공통으로 적용한다. 읽기 전용 안내는 동일한 180px 영역 안에 가로 가운데·세로 중간 정렬하고 구분선을 표시하지 않는다.
- 설정창과 `PageInfoPanel`은 `SettingsPanelChrome`의 공통 헤더·탭 레이아웃을 사용한다. 헤더는 메인 툴바의 줄 높이(상하 여백 포함 39px), 탭 메뉴 줄은 높이 58px, 아이콘은 24px로 어드민 표 머리글(`STOCK_HEADER_ROW_PX`, 58px)과 정렬한다. 높이·기본 틀 변경은 이 공통 컴포넌트에서 관리하고, 아래 설정 항목의 높이와 내부 배치는 유지한다. 홈은 `종목 구성 → 색상`, Graph는 `그래프 → 종목 구성 → 색상`, 커스텀은 종목·업종 화면 모두 `커스텀` 단일 탭을 표시한다. 커스텀은 직접 자유롭게 만든다는 뜻의 손그림 선·펜 아이콘을 쓴다. MARKETRY·거래소의 설정 본문은 첫 항목 높이인 180px 안에 번호 없이 `읽기 전용`과 `내 분류만 가능`을 두 줄로 가로 가운데·세로 중간에 표시한다. 이름과 선택 밑줄은 맵·어드민과 같은 높이에 둔다. 홈의 `요약 지도`, `그룹 등락률 (%)`, `시장 요약`은 제목을 잡고 가로로 끌어 배치하며, 순서는 브라우저에 저장한다. 홈 캡처 팝업에는 전체 캡처와 현재 좌측·중앙·우측 항목별 캡처 버튼을 둔다. 맵 캡처 팝업에는 모니터·모바일 영역 선택을 둔다. 전체 화면 캡처는 좌우 4px 여백을 포함한다. 홈 부분 캡처와 맵 모바일 캡처는 같은 810×1080 기준 프레임을 사용한다. 맵 모바일 캡처는 좌우·위쪽에 4px 프레임 여백을 두고, 스크린샷 이미지에서 하단 4 CSS px를 잘라 810×1080에 맞춘다.
- 설정창에서 마지막으로 고른 탭은 페이지별로 브라우저에 저장한다. 다시 열거나 새로고침해도 복원하고, 현재 계정에서 사용할 수 없는 탭은 첫 번째 탭을 표시한다.
- 상단 영역의 캡처 버튼 왼쪽에는 안쪽으로 감기는 소용돌이 화살표 아이콘의 브라우저 저장값 초기화 버튼을 둔다. 확인하면 이 사이트의 `localStorage`와 `sessionStorage`를 모두 비우고 새로고침한다. 이후 같은 브라우저 저장소에 추가한 기능도 함께 초기화한다. 서버 저장값과 로그인 쿠키는 지우지 않는다.
- 브라우저 저장값 초기화 확인창은 초기화 질문 아래에 설정창 위치·설정 탭 선택·캡처창 선택을 회색 예시로 보여 주고, 그다음 줄에 서버 저장값은 유지된다고 알린다.
- 커스텀 업종 화면 설정창은 `1) 업종 추가 → 2) 변경 내역` 순서로 둔다. 상하 관계 이동은 업종 목록의 번호 배지를 끌어 놓을 수 있는 줄에 놓는 방식으로만 시작하고, 별도의 `업종 재배치` 항목이나 이동 안내 팝업은 두지 않는다. 끄는 동안 끌고 있는 업종을 뺀 다른 줄의 번호 배지는 같은 크기·같은 자리에서 아이콘으로 바뀐다: 놓을 수 있는 줄은 `↲` 모양 화살표(회색 배지, 커서가 올라가면 청록으로 채움), 놓을 수 없는 줄은 ✕(더 어두운 회색 배지)이다. 놓을 수 있는 줄에도 줄마다 선은 긋지 않고, 지금 커서가 올라간 한 줄만 줄 전체 높이(29px)의 청록으로 채운다(선·세로선 없음). 끌고 있는 업종의 미리보기 막대에도 위·아래 선을 두지 않는다. 대분류·중분류·소분류 이름 바로 왼쪽에도 같은 크기의 배지가 끌 때만 나타나(업종명 앞 배지와 같은 10px 간격, 이름 자리는 그대로) 대분류 머리글만 `↲`(최상위로 이동), 중·소분류 머리글은 ✕다. 대분류 머리글에 커서가 올라가면 이름이 있는 윗줄(29px) 전체가 줄과 같은 청록으로 채워진다. 번호 배지 이동은 포인터 위치로 대상 행을 판정한다. 업종 순서는 시가총액 합이 큰 순(같으면 가나다순)이 기본이고, 아랫줄 머리글을 눌러 열마다 바꾼다. 순서를 직접 바꾸는 손잡이·저장 순서·`사용자 지정 순`은 두지 않는다(2026-10-29). 대·중·소분류 필터와 일괄 변경 팝업의 보기 순서는 `가나다 순 / 시가총액 순`(기본 시가총액 순)이고, 열 필터 팝업(업종 표·종목 표)의 모양은 이름표 줄(대·중·소분류 필터는 오른쪽에 보기 순서 두 칸), 검색창, `전체 선택`·`전체 해제` 배지 버튼, 목록 순이다. 검색창과 두 배지 버튼은 항목이 10개 이상일 때만 둔다(적은 필터는 이름표 줄과 목록뿐이다). 두 배지 버튼은 지금 상태와 맞는 쪽이 청록(`--brand-surface`)으로 눌러진 상태로 보이고(전부 체크 → `전체 선택`, 하나도 체크 안 됨 → `전체 해제`, 일부만 체크 → 둘 다 회색), 목록 전체(검색으로 가려진 항목 포함)를 기준으로 한다.
- 커스텀 업종 표의 번호 배지 글자는 굵기 500으로 맞춘다. 번호 배지 오른쪽과 업종명 사이는 대·중·소분류 모두 10px로 맞추고, 하위 업종 추가 입력 글자의 시작선도 업종명과 맞춘다. 드래그 미리보기의 번호·업종명 위치와 글자 굵기도 일반 행과 맞춘다. 업종명 시작 위치는 내 기준·MARKETRY·거래소 업종 표 모두 행 왼쪽에서 50px이다. 내 기준 업종 표의 헤더(58px)는 반으로 나눠 윗줄(29px)에 분류 이름·개수·검색 필터, 아랫줄(29px)에 MARKETRY·거래소와 같은 `업종`·`시가총액 합`·`종목 수` 정렬을 두고(한 열 안에서 50:25:25), 세 업종 표의 정렬 아이콘은 모두 글자 옆 ⇅이다(위·아래 꺽쇠는 29px 줄에 들어가지 않는다). 업종 이름 옆의 하위 업종 개수 괄호는 두지 않는다. 삭제할 수 없는 대분류 `신규 상장`은 MARKETRY·내 분류 업종 표에서 이름을 서브 노랑(`--sub-yellow`)으로 칠하고, 마우스를 올리면 공통 툴팁으로 `신규 상장시 이 그룹으로 자동 배정됩니다.`와 둘째 줄 괄호·회색 `(거래소 모드에서는 거래소 기준으로 배정됩니다.)`를 보여 준다. 공통 툴팁은 `~~글자~~`로 감싼 부분을 회색(`--ui-control`)으로 그린다.
- 커스텀 종목 화면 설정창은 `1) 일괄 변경 → 2) 변경 내역 → 3) 간편 업종 분류 → 4) 초기화` 순서로 둔다. 초기화는 로그인 사용자의 업종 목록과 종목 분류를 초기화한다. 초기화 버튼은 버튼 영역의 너비를 채우고 등락률 범례의 +8% 빨강(`#BC2F2F`)을 쓴다.
- 하위 업종 추가 입력은 성공하면 닫고, 실패하면 입력한 이름을 유지한다. 연속으로 더 추가하려면 대상 행의 `+`를 다시 눌러 입력을 연다. 생성되거나 이동한 업종은 행 배경색으로 표시하고 화면 안으로 스크롤한다.
- 설정창 슬라이더 아래 눈금은 트랙과 4px 간격을 두고, 보통 13px 글자를 쓴다. 선택된 눈금은 흰색·중간 굵기, 나머지는 흐린색·기본 굵기다. 등락률 색상 편집 막대는 눈금 사이가 좁아 12px, 선택값 배지는 11px로 둔다.
- 제외 업종과 배너 목록은 한 번에 4개(각 20px, 사이 4px)가 보이고, 네 개를 넘으면 목록 안에서 스크롤하며, 표시 높이를 넘을 때만 트랙과 손잡이를 보인다. 두 목록은 스크롤 유무와 관계없이 오른쪽에 8px 여백을 유지해 행과 호버 배경의 너비를 같게 한다.
- 커스텀 업종의 대·중·소분류 목록은 스크롤이 필요한 열에 반투명 손잡이를 표 위에 겹쳐 표시하며, 스크롤바가 열의 내용 너비를 줄이지 않는다.

### 모바일 지도 캡처 회귀 방지

- 모바일 전용 복제 레이아웃은 `MapPage.tsx`의 `[data-map-mobile-capture-frame]` 안에만 둔다. `revealMobileCapture`는 스크린샷 복제본의 툴바만 다시 구성하므로, 모바일 정렬을 고칠 때 실제 지도 툴바나 `main-settings-row`의 크기·위치를 바꾸지 않는다.
- 복제 툴바의 기준 배치는 한 줄이다: 좌측에 MAP 라벨이 걸친 100px K-STOCK 배지·날짜·시계/시간·세션, 그 다음 등락률 기준 버튼 하나를 둔다. 우측 끝에는 분류 배지를 둔다. 복제 시계는 새로고침 아이콘으로 바뀌지 않도록 고정한다. 등락률 버튼은 선택된 기준명만 보라색 배경의 정적 칩으로 복제하며 메뉴는 열리지 않는다. 칩 높이는 26.25px로 유지한다. 캡처 판의 상단 여백은 프레임 위쪽에서 툴바 배지까지 8.75px로 맞춰 텔레그램 홈 판과 같다. 텔레그램 홈·지도 810×1080 이미지의 툴바는 모든 배지·버튼의 위치와 크기, 내부 글자의 크기와 위치를 같은 기준으로 유지한다.
- 하단 여백은 `screenshotToPreview.ts`에서 모바일 캡처 이미지의 마지막 4 CSS px를 직접 잘라 맞춘다. 투명/배경색 행 탐지에 의존하지 않는다. 프레임의 `height`·하단 패딩을 조절하면 히트맵의 실제 배치와 캡처 범위가 함께 바뀌어 지도 잘림·빈 띠를 다시 만들 수 있으므로, 여백 수정은 이 이미지 후처리 경로를 기준으로 한다.
- 레이아웃을 바꾼 뒤 Orca의 스크린샷 팝업에서 모니터를 한 번 선택한 다음 모바일을 다시 선택해 새 이미지를 만든다. 하단 여백이 좌우 4px와 비슷한지, 마지막 타일이 잘리지 않았는지, 상단 툴바가 한 줄인지, 선택된 등락률 버튼과 우측 분류 배지가 제자리에 있는지 확인한다. 미리보기만 보고 끝내지 말고 실제 복사 이미지에도 같은 후처리가 적용되는지 확인한다.

- **업종 단계 이름**: 깊이 순서대로 대분류 · 중분류 · 소분류 · 세분류. 지금은 3단계(대·중·소분류)만 쓰고, 4단계(세분류)는 이름만 정해 뒀고 거의 만들지 않을 예정이다(거래소 새 업종 분류 발표를 보고 최종 정한다). 5단계 이상은 지도 위에서 자리가 모자라 만들지 않는다. 이동 경로 툴팁이 이 이름을 쓴다(`대분류로 돌아가기`).
- 화면의 **Basis**(설정창 맨 아래)는 코드에서 `Taxonomy`(분류 선택)다. 코드의 `basis`는 이것이 아니라 일간/시간외 등락률 기준이며, 서버에 보내는 요청 항목 이름(`basis=afterHours`)으로만 남아 있고 코드 안에서는 `ChangeRateMode`라고 부른다.
- **히트맵**: 사각형으로 쪼갠 지도 그림은 화면·검색 문구·코드 모두 `히트맵`/`Heatmap` 하나로 쓴다(2026-10-28 통일). 구글·네이버 검색에서 "히트맵"이 압도적이라 처음 쓰던 "트리맵"/`Treemap`을 바꿨다. 예외는 외부 라이브러리 `d3-hierarchy`가 제공하는 함수 이름(`treemap`, `treemapSquarify`, `treemapBinary`)뿐이다. 새 코드·문서·화면에 "트리맵"/`Treemap`을 다시 쓰지 않는다.
- "콤보박스"라는 말은 화면과 코드에서 쓰지 않는다. 드롭다운이라고 부른다.
- **업종과 그룹(서비스의 핵심 개념)**: `업종`은 거래소가 기존에 나눈 분류이고, 그 기준이 마음에 들지 않으면 사용자가 새로 `그룹`을 지어 보라는 것이 서비스의 핵심이다. MARKETRY 분류의 삼성 그룹·SK 그룹·S7 같은 묶음과 사용자가 직접 만드는 내 분류도 이렇게 새로 지은 그룹이다. 화면 글자는 맥락마다 다르게 쓰이고 있어서(2026-10-28 조사: 화면 문구에 `업종` 112건은 설정·표·조작에, `그룹` 13건은 홈 `그룹 등락률 (%)`·박스 `그룹 시총`·가이드에) **한꺼번에 바꾸지 않는다.** 화면을 손볼 때 그 맥락을 보고 하나씩 정하고, 정한 것은 아래에 적는다.
  - 정한 것: 홈 `그룹 등락률 (%)`·박스 `그룹 시총`은 그대로 둔다. 가이드와 검색 설명에서는 `업종 그룹`이라고 쓰지 않고 새로 지은 묶음을 `그룹`이라고 쓴다.
  - 쓰지 않는 것: `업종 그룹`(두 말이 섞임). 옛 "그룹 페이지"는 지금 그래프(Graph) 페이지다.
- **업종 / 거래소 분류**: 화면의 "업종"은 우리 분류의 한 덩어리(대·중·소분류 어느 단계든, 영어 `Sector`)이고, 종목 표의 "거래소 분류"은 거래소(키움 `upName`)가 정한 업종(코드 `industry`)이다. 화면 영어는 `Sector`만 쓰고 `Industry`는 쓰지 않는다. Custom 페이지 주소는 `/custom/sector`와 `/custom/stock`이다.
- 분류 갱신 시각 필드는 `taxonomyUpdatedAt`이다. 서버는 한동안 옛 이름 `classificationUpdatedAt`도 같이 보내며, 화면 전환이 끝난 뒤 서버에서 옛 이름을 지운다.

## 팝업 규칙

팝업은 **확인**·**정보**·**주의** 세 종류다. 확인은 `취소`·`확인`, 정보는 `닫기`, 주의는 확인과 같은 `취소`·`확인` 동작을 쓰되 확인 버튼과 종류 배지는 등락률 범례 +8% 빨강(`#BC2F2F`)으로 표시한다. 확인은 일반 확인이 필요한 작업, 주의는 삭제·초기화·탈퇴처럼 되돌리기 어렵거나 영향이 큰 작업에 쓴다. 새 팝업을 만들 때 이 세 종류 중 하나를 정한다. 메시지 팝업은 이 세 종류뿐이며 관리자 화면도 예외가 없다(관리자 전용 색·테두리·제목을 따로 두지 않는다).

| 종류 | 배지 | 배경 | 클릭 | 예 | 코드 |
|---|---|---|---|---|---|
| **확인** | 청록 "확인" | 화면 전체를 어둡게 덮음 | `취소`·`확인`, 뒤 화면 클릭을 막음 | 저장하기·되돌리기 확인 | `AppDialogHost`(`appConfirm`) |
| **정보** | 회색 "정보" | 일반 정보는 화면 전체를 어둡게 덮음. NXT 시간대 공지는 배경을 덮지 않음 | `닫기`. 일반 정보는 닫기 전까지 뒤 화면 클릭을 막고, NXT 공지는 뒤 화면 사용 가능 | 작업 결과·실패, NXT 시간대 안내 | `AppDialogHost`(`appAlert`), `NxtOnlyNotice` |
| **주의** | +8% 빨강(`#BC2F2F`) "주의" | 화면 전체를 어둡게 덮음 | `취소`·빨강 `확인`, 뒤 화면 클릭을 막음 | 업종·종목 초기화, 탈퇴, 삭제 | `AppDialogHost`(`appWarnConfirm`) |

- **정보 제목은 "동작 + 결과"로 쓴다**: `적용 완료`·`적용 실패`, `일괄 변경 완료`·`일괄 변경 실패`, `업데이트 완료`·`업데이트 실패`, `저장 실패`, `불러오기 실패`, `삭제 실패`, `이동 실패`처럼 결과가 제목에 드러나게 한다. 막혀서 못 하는 경우는 `추가 제한`·`삭제 불가`·`이동 제한`·`요청 실패`, 바뀐 것이 없으면 `적용 없음`이다. 확인·주의 제목은 결과가 없으므로 "대상 + 동작"(`업종 삭제`, `버전 불러오기`)이다.
- **확인·주의 본문 모양**: 대상이 있으면 첫 줄에 `[대상]`만 쓰고(조사·종류 낱말 없이), 둘째 줄에 동작(`~하시겠습니까?`), 덧붙임은 셋째 줄부터 쓴다(예: `[반도체]` / `삭제하시겠습니까?` / `하위 업종 …`). 대상은 업종명 또는 버전 시각이다. 대상 이름이 없는 문장(색상 초기화, 저장하기 등)은 한 줄이다. 동사는 `업데이트하시겠습니까?`처럼 명사와 붙여 쓴다(`업데이트하다`가 한 낱말이라 띄우면 맞춤법 오류다).
- **오류·빈 화면 문구**: 모두 문장이라 마침표로 끝낸다. 하려던 동작이 실패했을 때는 `~하지 못했습니다.`(예: `저장하지 못했습니다.`), 원래부터 안 되는 것은 `~할 수 없습니다.`(예: `삭제할 수 없습니다.`)다. 다시 해 볼 만한 실패 뒤에는 `잠시 후 다시 시도해 주세요.`를 붙인다. 빈 목록은 `검색 결과가 없습니다.`·`표시할 데이터가 없습니다.`처럼 `~가 없습니다.`로 쓴다(`결과가 없습니다` 같은 짧은 줄임말은 쓰지 않는다).
- **본문에 업종명이나 버전 시각을 쓸 때는 `[ ]`로 감싸 첫 줄에 `[이름]`만 적고 다음 줄에 내용을 적는다**(확인·주의·정보 모두 같다. 예: `[반도체]` / `일괄 적용 완료되었습니다.`, `[2026-10-13 18:42]` / `불러오시겠습니까?`). 종목 이름과 일반 수는 감싸지 않는다.
- 제목 앞에 종류 배지(`PopupKindBadge`)를 붙이고, 배지 오른쪽에 제목을 적는다. 제목 뒤에 경고·주의 아이콘을 붙이지 않는다. 확인·주의 제목은 짧게 "대상 + 동작"으로 쓴다(예: "업종 삭제", "버전 불러오기", "색상 초기화"). 결과 정보의 제목은 "동작 + 결과"로 쓴다. 제목은 확인은 `appConfirm`, 정보는 `appAlert`, 주의는 `appWarnConfirm`으로 넘긴다.
- 공통 양식: 말풍선색 창, 굵은 제목. 정보의 `닫기`와 확인·주의의 `취소`는 회색이다. 확인 버튼은 확인에서 청록, 주의에서 +8% 빨강(`#BC2F2F`)이다. 확인·정보·주의 메시지 팝업 버튼은 기존 라운딩을 유지하고, 외곽 테두리와 포커스 외곽선은 표시하지 않는다. 키보드 포커스는 배경색 변화로 구분한다.
- 버튼은 정보에서 오른쪽 `닫기` 하나, 확인·주의에서 왼쪽 `취소` → 오른쪽 `확인` 순서로 둔다. 창이 열리면 정보는 `닫기`, 확인·주의는 `취소`에 키보드 초점을 둔다. Tab은 창 안의 버튼만 순환하고, Esc는 정보 창을 닫거나 확인·주의를 취소한다. 창을 닫으면 이전 초점으로 돌아간다. 어두운 배경을 눌러도 창은 닫히지 않는다.
- 확인·정보·주의·NXT 안내·로그인 팝업의 가로 중심은 메인 영역(`data-main-area`), 세로 중심은 전체 화면을 기준으로 맞춘다. NXT 안내는 비차단 정보 팝업이며 `data-capture-ignore`로 공유 이미지에 담지 않는다. 업데이트·롤백 로딩 원의 위치는 이 규칙에 포함하지 않는다.
- 크기: 확인·정보·주의 팝업은 폭 384px(`max-w-sm`), 높이 198px로 통일한다(본문 3줄 기준, `POPUP_SIZE_CLASS`). 본문이 3줄을 넘으면 줄 수만큼 높이를 늘린다. 버튼 줄은 항상 맨 아래에 붙고, 본문과의 간격은 12px이다.
- **스크린샷 창**: 상단 영역의 스크린샷 버튼(점선 사각형 아이콘)을 누르면 뜨는 메인 영역 스크린샷 미리보기 창(다운로드·클립보드·닫기). 확인·정보·주의 팝업과 별개의 종류이고, 코드 이름은 `ScreenshotModal`이다. `내 기준`에 등록된 종목이 없으면 홈 전체·부분, 맵, 그래프와 커스텀 페이지의 빈 분류 캡처 미리보기에 MARKETRY 로고와 등록 안내, 커스텀 바로 가기를 표시하고 그 화면을 클립보드로 복사한다. 텔레그램 홈 캡처도 같은 빈 상태 안내를 쓴다.

## 드롭다운 규칙

버튼을 눌러 그 아래에 목록이 뜨는 창은 **드롭다운**이다. 화면이 어두워지는 메시지 팝업과 다른 종류이며(위 "팝업 규칙"), 아래 틀을 공통으로 쓴다. 기준은 대·중·소분류 필터 창(`ColumnFilterButton`)의 큰 틀이다. 글자 크기·항목 높이까지 맞추지는 않는다(2026-10-28 통일).

- **대상**: 분류 필터(`ColumnFilterButton`), 설정 드롭다운(`SettingsDropdown`), 변경 내역(`ChangeHistoryControls`), 발행 버전 롤백 목록(`MarketryPublishControls`), 배너 시간 선택의 시·분 목록(`BannerTimePicker`), 상단 메뉴 목록(`NavSubBar`), 등락률 기준 목록(`ToolbarControls`). 프로필 메뉴(`NavBar`)는 그림자만 맞췄다.
- **창 틀**: `--ui-panel` 바탕, `border-ui-border` 테두리(관리자 전용 목록도 같은 색, 골드 쓰지 않음), 둥근 모서리(`rounded-md`), `shadow-xl`.
- **안쪽 여백**: 창 위아래 여백은 두지 않는다. 항목은 창 끝까지 닿는 직각 줄이고 창의 둥근 모서리 안에서 잘리며(`overflow-hidden`), 마지막 항목의 선택 색 아래에 빈 띠가 남지 않는다. 분류 필터만 머리글 위 여백 8px가 있다. 항목 좌우 여백은 12px이다.
- **항목 상태**: 마우스를 올리거나 키보드 포커스가 오면 흰색 10% 배경으로 구분한다. 항목 사이에 구분선을 두지 않는다.
- **간격**: 여는 버튼과 4px 떨어뜨린다(바탕색이 같아 붙으면 구분이 안 된다). 위로 열릴 때도 같다. 라벨이 있는 칸은 목록 기준을 라벨이 아니라 버튼에 둔다. 기준은 **눈에 보이는 버튼**이다. 감싸는 칸이 버튼과 크기가 다르면 그만큼 보정한다(상단 메뉴·프로필 메뉴·등락률 기준).
- **공통 코드**: 간격(`DROPDOWN_GAP_PX`), 창 틀(`DROPDOWN_PANEL_CLASS`), 항목(`DROPDOWN_ITEM_CLASS`)은 `src/components/dropdownStyle.ts`에 모아 두었다. 새 드롭다운은 창마다 클래스를 새로 적지 말고 이 값을 쓴다.
- **스크롤되는 목록**: 목록 높이를 항목 수의 정수배에 맞추고 항목 단위로 스크롤이 멈추게(snap) 한다. 어느 위치에서 멈춰도 반쯤 잘린 항목이 남지 않는다. 시간 선택은 항목 25px × 6 + 테두리 2px = 152px, 분류 필터는 항목 28px × 10 = 280px, 변경 내역은 25px × 10 = 250px이다. 코드는 `dropdownStyle.ts`의 `DROPDOWN_SCROLL_CLASS`·`DROPDOWN_SNAP_ITEM_CLASS`·`dropdownListMaxHeight()`를 쓴다. 항목 높이를 바꾸면 보이는 줄 수와 곱한 높이도 함께 바꾼다.
- **롤백 목록**: 최근에 올린 5개 버전만 한 줄씩 보여 주며 안내 문구는 두지 않는다. 업데이트할 때 적은 메모가 있으면 메모만 보이고 시각(`2026-10-28 15:53`, 대괄호 없음)은 마우스를 올렸을 때 공통 툴팁으로 뜬다. 메모 없이 올린 옛 버전은 시각이 그대로 보인다. 서버에는 더 오래된 버전도 남아 있다(`ROLLBACK_VERSION_COUNT`).
- **포커스 테두리**: 버튼의 브라우저 기본 포커스 테두리(파랑·흰색 두 겹)를 숨기는 규칙은 `body` 전체에 적용된다(`index.css`). `#root` 밖으로 따로 그려지는 드롭다운에도 같다. 텍스트 입력칸만 예외다.
- **각자 유지**: 체크박스·검색칸이 든 분류 필터의 내용 구성, 변경 내역의 되돌림 구간 청록 표시, 현재 페이지 표시(상단 메뉴)는 내용이 달라 그대로 둔다.

## 모바일 글 페이지 틀

폭 768px 미만에서 글 페이지(가이드·개인정보처리방침·데이터·이용약관·문의)는 PC 틀(설정창 + 고정 상단바) 대신 `MobileDocumentShell`을 쓴다(2026-10-28). 글 내용(제목·구획·본문)은 PC와 같은 한 벌이고 틀만 다르다.

- 설정창과 고정 상단바 없이 본문이 전체 폭이다. 상단은 로고 한 줄(`MobileTopBar`, 44px)과 페이지 이름(예: `GUIDE`)이다.
- **상단 로고 줄 공통(`MobileTopBar`)**: 폭 768px 미만의 홈·글 페이지와 지도 화면은 같은 로고 줄(44px, 왼쪽 로고 최대 폭 148px·가운데 페이지 이름 14px·오른쪽 로그인 또는 계정 메뉴)을 쓴다(2026-10-29). 페이지 이름은 홈은 가운데 제목 없이 두고, 글 페이지는 `GUIDE` 등, 지도는 `MAP`이다. 홈·지도의 제목 줄(`국내 업종 히트맵`·날짜)은 이 로고 줄 아래에 두고, 예전의 작은 `DESIGN YOUR MARKET` 문구는 로고에 들어 있어 뺐다. 노치가 있는 기기에서는 안전 영역만큼 높이를 더한다.
- **모바일 지도의 뒤로가기**: 대분류·중분류·종목으로 한 단계 들어갈 때마다 브라우저 기록을 한 칸씩 쌓아(PC 지도 화면과 같은 방식), 뒤로가기가 사이트를 떠나지 않고 한 단계씩 올라간다. 전체 화면에서 한 번 더 누르면 이전 페이지로 나간다. 시장(국내 증시·코스피·코스닥)을 바꾸면 주소가 달라지므로 쌓인 칸은 정리하지 않는다. 앞으로가기로 들어갔던 단계는 복원하지 않고 지금 화면에 맞는 칸으로 되돌린다. 다른 페이지에 갔다가 뒤로 돌아오면 남은 칸을 걷어 내 처음 상태에 맞춘다.
- **모바일 지도 설정 줄과 화면 구성**: 목표가 "설정을 바꾸면 지도가 변하는 과정을 보는 것"이라 설정이 지도를 덮지 않는다(2026-10-29). 설정을 열면 화면 아래에 낮은 설정 줄이 붙고(덮는 시트·어두운 배경 없음), 지도는 남은 칸으로 줄어들어 전체가 보인다. 닫혀 있을 때의 아래 바(28px)도 지도 위에 겹치지 않고 지도 아래 자리를 차지하며, 안에는 가운데 가로 손잡이 막대와 왼쪽의 기준 시각(`2026-10-23 (금) 20:00`, PC 상단 시각 표기와 같은 형식)만 둔다. 열린 상태에서도 같은 손잡이 줄(28px)을 유지한다. 줄을 누르면 열고 닫으며, 손가락으로 위아래로 끌면 설정 줄과 지도가 함께 움직이고 놓은 위치에 따라 열리거나 닫힌다. 손잡이는 가운데 가로 막대다. X 아이콘·`설정`·`닫기` 글자는 두지 않는다. 설정 줄과 닫힌 바의 위쪽 모서리는 16px로 둥글게 한다.
  - **설정 항목**: `분류 기준`(MARKETRY·거래소·내 기준) → `마켓`(국내 증시·코스피·코스닥) → `박스 크기`(동일·균형·시총 비례) 세 개다. 화면마다 다른 줄은 맨 아래에 둔다(GRAPH는 박스 크기 대신 `업종 단계`). **폰의 기본값은 국내 증시 · 시총 비례 · MARKETRY**다(박스 크기는 PC 설정과 따로 `mobile.boxSizeMarketCapRatio`에 두고 기본 100, 분류 기준은 브라우저에 저장한 선택이 없을 때 MARKETRY, 마켓은 주소에 없으면 전체). 위쪽의 업종/주식 전환 버튼과 `업종 분류`(대·중·소분류)·`표시 종목` 줄은 지웠다.
  - **눌러서 들어가는 순서**: 하위 분류가 있으면 그 분류 지도로, 없으면 바로 종목으로 간다(MARKETRY·내 기준은 대분류 → 중분류 → 소분류 → 종목, 거래소는 대분류 → 종목). 그래프 화면과 공유하는 저장 단계 값에는 얽매이지 않는다.
  - **위쪽 경로 줄**: PC 지도 화면의 이동 경로와 같은 모양이다(굵은 글씨 16px, 높이 36px, 맨 앞 흰색 세로 막대, 단계 사이 `›` 없음). 맨 앞은 전체 마켓에서 국내 증시, 그 밖에는 고른 마켓 이름(코스피·코스닥)이고, 앞 단계는 이름 오른쪽에 되돌아가기 아이콘(↩, `ReturnArrowIcon`)이 붙은 흰 글씨 버튼(누르면 그 단계로 되돌아감), 마지막은 현재 위치라 강조색 글씨만이다. 단 마켓 이름만 표시할 때는 흰색이다. 배지로 만들지 않는다. 맨 처음에도 항상 두어(마켓 이름만 흰색으로 보임) 단계에 들어갈 때마다 지도 크기가 달라지지 않게 한다.
  - **주식 지도**: 시가총액 상위 30종목을 고정으로 그린다. 종목명은 칸이 좁으면 PC 지도의 종목 박스와 같은 규칙(`stockLabelFit`의 `fitStockLabel`: 공백 > 접미어 우·지주·홀딩스 > 영문·한글 경계·그룹명 뒤 > 가장 균형 잡힌 자리)으로 두 줄로 나눠서(2026-10-29부터 PC와 공통) 390px에서 30칸 모두 이름과 등락률이 들어간다(나누지 않던 때는 30칸 중 4~10칸이 빈 칸이었다). 칸을 누르면 지도 위쪽(손가락에 가리지 않는 자리)에 종목 정보 카드(정식 종목명, 코드·시가총액, 칸 색의 등락률 배지)가 뜨고, 카드를 누르거나 같은 칸을 다시 누르거나 5초가 지나면 닫힌다.
  - **종목 찾기**: 예전 주식 보기의 `종목 찾기`(검색·목록)는 지도에 필요한 기능이 아니라서 화면에서 빼고 `src/components/MobileStockList.tsx`로 분리해 두었다(어디에도 연결돼 있지 않다).
  - 390px 기준으로 지도는 설정 닫힘 약 728px(위쪽 경로 줄 포함), 열림 약 606px이다.
- **모바일 버튼·배지 규격(PC 기준을 폰 크기로)**: PC 설정창 버튼과 같게 테두리 없이(`border-0`) 모서리 4px, 바탕은 기본 `bg-ui-control`·선택 `bg-brand-surface`, 글자는 중간 굵기 흰색이다. 폰은 누르기 쉽게 높이 32px·글자 13px로 키우고, 폰 화면에서 `rem`이 80%로 줄어드는 영향을 받지 않도록 px로 고정한다. 버튼에 `border-0`을 빼면 브라우저 기본 테두리가 나와 어색해지므로 반드시 붙인다. 홈·지도 위쪽 제목 줄(`국내 업종 히트맵`)은 로고 줄·시장 선택과 겹쳐 지도를 가려서 없애고(화면 낭독용 제목만 남김), 기준 시각은 아래 설정 바 줄로 옮겼다. 지도 바깥 테두리도 뺐다.
- **모바일 화면 모드 버튼**: 모바일 상단 줄 오른쪽, 프로필(로그인) 왼쪽에 해·달 아이콘 버튼(40×44px)을 둔다. 지금 모드를 그림으로 보여 주고(야간=달, 주간=해) 누르면 반대 모드로 바뀐다. 색은 `docs/ui-colors.md`의 `모바일 주간모드`를 따른다.
- **모바일 화면 구성(2026-10-29)**: 새 경로를 만들지 않고 PC와 같은 주소를 쓴다. `종목 지도`=`/map/korea`(마켓은 `kospi`·`kosdaq`, 업종만 보려면 `?sector=대분류`, PC 지도와 같은 주소), `업종 지도`=`/home?map`(PC 홈은 `?map`을 읽지 않는다), `그룹 등락률`=`/graph/korea`. 업종 지도에서 업종을 누르면 그 업종의 종목 지도(`/map/korea?sector=업종`)로 이동하고 중분류·소분류 단계는 없다(그래프만 단계별로 들어간다). 상단 제목을 누르면 종목 지도 → 업종 지도 → 그룹 등락률 순서로 이동한다(마켓 유지). 종목 지도는 시총 상위 30개를 두 손가락으로 확대·이동하고, 짧게 누르면 종목 카드가 2초간, 길게 누르면 닫을 때까지 뜬다.
- **모바일 홈**: `/home`은 공통 로고 줄과 하단 정보 줄을 유지하고 심볼·로고·슬로건, 브랜드 초록색의 `종목 지도`·`업종 지도`·`그룹 등락률`·`가이드` 세로 배지와 `업종 분류는 PC에서만 가능합니다.` 안내를 하나로 묶어 본문 가운데에 둔다. 각각 `/map/korea`(종목 지도), `/home?map`(업종 지도), `/graph/korea`(그룹 등락률), `/info/guide`로 이동한다. 모바일 그래프는 PC 홈의 그룹 등락률처럼 막대를 등락률 순으로 보여 주며, 업종을 눌러 하위 분류와 종목 그래프로 들어간다. 상단 경로와 뒤로가기는 모바일 지도와 같다. 하단 설정 줄은 지도와 같은 손잡이 방식이며 마켓·분류 기준을 제공한다. 지도 마켓 선택은 `/map/korea`·`/map/kospi`·`/map/kosdaq` 주소를 쓴다.
- **홈 주소(`/`)**: 첫 화면 `/`는 곧 `/home`으로 옮겨 가지만 폰 화면 판정이 먼저 일어나므로 `isMobileMarketPath`에 포함한다(2026-10-29, 빠져 있어 폰에서 `marketry.co.kr`로 들어가면 PC 안내가 떴다).
- **모바일 로그인 팝업**: PC와 같은 팝업 구성과 로그인 방식을 유지하고, 모바일에서는 로그인·닫기 버튼을 최소 44px 높이와 14px 글자로 표시한다. 화면 높이가 부족하면 팝업 내부를 스크롤한다.
- **상단바 고정**: 상단바는 스크롤해도 항상 화면 위에 보인다(`sticky`). 처음에는 아래로 스크롤하면 숨기고 위로 올리면 다시 보이게 했으나(`useHideOnScrollDown`), 상단바가 48px로 작아 숨겨서 얻는 면적이 작고 PC와 같은 방식이 더 예측하기 쉬워 항상 고정으로 바꿨다(2026-10-28, 사용자 의견).
- **이동 시 맨 위부터**: 글 페이지는 창 스크롤을 쓰므로, 링크로 다른 글 페이지에 들어가면 맨 위부터 보여 준다(`useNavigationType`이 POP이 아닐 때 `scrollTo(0, 0)`). 뒤로 가기(POP)는 브라우저의 스크롤 복원에 맡긴다.
- 하단 정보 줄은 면책 문구 → 정보 링크 → 저작권 순서로 두고 링크와 저작권은 가운데 정렬하며 줄임표 없이 줄바꿈해서 전부 보여 준다(`DisclaimerNotice`의 `wrap`).
- 모바일에서는 홈·지도·그래프·글 페이지가 열리고, 그 밖의 PC 전용 화면은 PC 화면 안내를 보여 준다.
- `/info`로 들어가면 가이드(`/info/guide`)로 이동한다.
- 모바일 설계 방향: 데이터·설정 값·색·문구·글 내용은 한 벌로 쓰고, 화면 틀(설정창→아래 시트, 상단 고정 축소)·조작(눌러서 들어가기)·지도 배율(종목 수 상한, 글자 크기 자동)만 모바일용으로 나눈다. 지도 설정 시트와 지도 화면의 상단 영역 축소는 다음 단계다.

## 운영자 전용 표시

운영자만 쓰는 것은 일부러 일반 규칙(한글·청록)에서 벗어나 **눈에 띄게** 만든다. 이것이 유일하게 허용하는 예외다.

- Custom 페이지 설정창의 `⚠ ADMIN` 띠와 `UPDATE`·`ROLLBACK` 버튼은 영어 대문자·빨간색이다(MARKETRY 맵을 바꾸는 작업이라 실수로 누르지 않게 튀게 둔다). 롤백 목록 줄은 메모(없으면 시각)만 보여 주고, 정보·확인 팝업 제목은 한글("업데이트 완료", "롤백 완료")이다. 업데이트 확인창에는 선택 입력 메모칸(20자)이 있고, 완료·롤백 창의 첫 줄은 메모가 있으면 `[메모]` 아래 줄에 시각, 없으면 `[시각]`이다.
- 운영자 전용 표시 색은 골드(`--admin-only`, 올림·선택은 밝힌 `--admin-only-hover`) 하나다. 상단 Admin 메뉴, 설정창 관리자 탭과 제목, 로컬 개발 화면 프로필 팝업의 관리자 전환 버튼(TEST 버튼과 배지는 중립 회색)에 쓴다. 팝업은 관리자 화면에서도 일반 팝업과 같은 모양이다(골드 테두리·제목을 쓰지 않는다).
- **광고 배너 자리(`AdBannerSlot`)**: 상단 로고 줄과 메뉴 줄 가운데의 빈 곳에 겹쳐 놓는 자리다. 상단 바 높이는 키우지 않고, 화면 맨 위에 붙이며 가능하면 화면 가운데에 둔다(설정창이 왼쪽에 있어도 같은 자리라 오른쪽 프로필·아이콘을 가리지 않는다). 메뉴(관리자는 Admin까지 5개)나 프로필 묶음에 걸리면 메뉴 끝과 프로필 시작을 화면에서 실제로 재서 순서대로 줄인다: 가운데에서 빈 칸 안쪽으로 밀기 → 메뉴 글자 앞 아이콘 숨기기(`html[data-nav-compact]`) → 작은 규격(728×90에서 468×60)으로 바꾸기 → 그래도 안 들어갈 때만 숨기기. 메뉴 줄 아래에는 8px 간격을 둬서 툴바가 96px에서 시작하고, 배너 아래 끝(90px)과 분류 배지 사이는 약 8px이다. 지금은 광고 회사가 없어 시험용 광고(`DevTestBanner`, 안에 "시험용" 표시)를 운영에도 끼워 두고, 광고 회사가 정해지면 실제 광고로 바꾼다. 광고가 없으면 아무것도 그리지 않는다(광고 회사는 미정, 규격·간격은 `AdBannerSlot.tsx` 위쪽 값만 고친다). 숨길 때도 광고 코드는 불러오지 않는다. 캡처 이미지에는 들어가지 않는다.
- **배너 작성**: 제목·내용·광고 이미지·연결·게시 일정을 편집한다. 메인 영역은 `1) 미리 보기` → `2) 배너 내용` → `3) 게시 일정` 순서로 나누고, 메인·설정 목록은 `게시` → `대기` → `종료` 세 구역으로 관리한다. 게시에는 현재 게재 중인 배너를, 대기에는 예약 배너와 미공개 상태인 기존 미예약 초안을, 종료에는 게재가 끝난 항목을 둔다. 상단 `AdBannerSlot`에는 현재 게재 시각에 해당하는 공개 배너만 노출한다. 대기 배너는 노출하지 않으며, 배너 미리보기는 화면 밖에서 문구 표시 한도를 계산하는 데 쓴다. 편집 순서는 제목 → 내용 → 연결이다. 제목·내용·연결 라벨은 같은 15px 중간 굵기와 22px 줄높이를 쓴다. 연결 주소는 선택 입력이며 비워 둬도 저장할 수 있다. 내용 입력칸 높이는 미리보기에서 실제 표시 가능한 줄 수와 줄높이에 맞춰 빈 여백이 남지 않게 한다. 입력 문구는 상단 배너 미리보기에서 잘리지 않는 범위까지만 허용한다. 입력칸 안에 문구 한계 점선이나 별도 안내문은 넣지 않는다. 게시 일정은 시작·종료 라벨을 같은 폭으로 한 줄 정렬하고, 날짜·시각 입력은 날짜 배지와 시각 배지를 분리해 표시한다. 종료 일자 프리셋은 종료 입력 오른쪽에 `7일`·`14일`·`30일`을 두고 시작 시각 기준으로 자동 계산하며 기본은 30일이다. 공지 배너 배경은 메시지 팝업과 같은 크림색(`--ui-popup`)으로 하고, 제목·본문은 어두운 글자로 표시한다. 공지 배지는 메시지 팝업의 정보 배지와 같은 중립 회색(`--ui-control`) 바탕과 흰 글자를 쓴다. 배지 크기는 작은 배너에서 12px, 기본 배너에서 14px다. 종류 배지는 `BannerTypeBadge`에서 공지는 중립 회색, 광고는 관리자 골드로 통일한다. 메인 전환 배지 순서는 `목록` → `새 공지` → `새 광고`다. 세 화면은 같은 공통 헤더 영역을 쓰며, 헤더의 상단·탭·구분선은 고정하고 구분선 아래 내용만 스크롤한다. `목록`은 `게시`·`대기`·`종료`를 각각 1·2·3번 구역으로 나누고, 상단 표시와 같은 728×90 크기로 미리 보여 주며 게시 시작·종료 시각을 설명 문구와 같은 14px 글자로 표시한다. 목록을 열어 둔 동안 상태를 갱신해 종료 시각이 지난 배너를 종료 구역으로 자동 이동한다. 예약 배너는 시작 시각까지 남은 시간을 24시간 미만이면 `n시간 뒤`, 24시간 이상이면 `n일 뒤`로 표시하고, 미예약 초안은 `미예약`으로 표시하고, 미예약 초안의 기간 표시는 `게시 기간: 미정`으로 한다. 예약 취소는 자동 게시를 중단하고 상태를 미예약으로 바꾸며 입력된 시작·종료 시각은 다음 게시·예약 시 사용할 값으로 보존한다. 대기 목록 항목을 선택하면 편집 화면에서 마지막 `게시` 또는 `예약` 버튼으로 처리한다. 메인 목록은 실제 배너 크기의 미리보기로 관리한다. 설정창은 1) 게시, 2) 대기, 3) 종료, 4) 배너 전환 간격 순서이며, 각 배너 목록은 높이 92px에 4개 항목을 보이고, 내용이 넘칠 때만 스크롤바를 표시한다. 전환 간격은 공개 배너 순환에 적용되는 서버 저장 설정이다. 목록에서 배너를 선택하면 해당 종류의 편집 화면에 저장된 내용을 불러온다. 목록 상태에서 `새 공지` 또는 `새 광고`를 누르면 그 종류의 새 입력 화면을 연다. 편집 중 같은 탭을 누를 때도 해당 종류의 새 입력 화면으로 전환한다. 기존 편집과 신규 작성은 같은 편집 화면을 쓰며, 신규 배너와 기존 초안은 시작 시각에 따라 `게시` 또는 `예약`을 눌러 저장 후 공개 승인한다. 게시·예약 중인 배너의 수정 버튼은 `저장`으로 표시한다. 종료 내역을 열면 재게시할 수 있도록 시작 시각을 현재로, 종료 시각을 30일 뒤로 준비하며 일정이 유효해야 `다시 게시` 또는 `재예약`이 가능하다. 게시·재예약과 저장은 성공 후 목록으로 돌아온다. 예약 취소는 자동 게시를 중단해 미예약 상태로 바꾸고, 입력된 일정은 다음 게시·예약에 쓸 값으로 보존한 뒤 목록으로 돌아온다. 배너 관리 기본 화면은 `목록`으로 연다. 게재 중 배너는 수정 화면에서 `종료`만 가능하고, 종료된 배너에서만 오른쪽 끝의 위험색 `삭제` 버튼을 보인다. 저장·게시·예약·종료·삭제 버튼 너비는 90px, 좌우 여백은 6px로 맞춘다. 예약 취소 시 내용과 입력 일정은 보존하되 목록은 `게시 기간: 미정`으로 표시하고 자동 게시가 꺼진 `미예약` 상태로 둔다. `n일 뒤`는 자동 게시가 예약된 항목에만 표시한다.
- 배너 목록의 `게시`·`대기`·`종료` 각 구역은 종료 시각이 최근인 순서로 표시하고, 종료 시각이 없는 항목은 해당 구역의 마지막에 둔다.
- 배너 목록의 일정은 제목 길이에 관계없이 모든 카드에서 제목 아래에 표시한다. 표기는 `게시 기간: 시작일 (요일) 시각 ~ 종료일 (요일) 시각` 형식을 쓰며, 종료 시각이 없으면 종료일 대신 `종료 없음`을 표시한다. 상단에 게재 중인 배너가 바뀔 때는 다음 배너가 아래에서 올라와 이전 배너를 밀어 올리는 전환을 적용하고, 움직임 줄이기 설정에서는 즉시 전환한다.
- **메인 영역 편집 라벨**: 항목명은 15px 중간 굵기 흰색, 조작부는 기존 13px 중간 굵기 흰색 양식을 쓴다. 보조 설명만 `--ui-muted`로 표시한다.
- **운영자 설정창**: 회원·배너·대시보드·메시지 페이지의 설정창 표시 제목은 공통 `Admin`이다. 페이지별 탭 저장 키는 유지하며 제목 왼쪽 세로 강조 막대와 관리자 탭은 운영자 색(`--admin-only`)을 쓴다. 선택된 탭은 선명하게, 비선택 탭은 흐리게 보여 구분한다.
- **메시지 설정창**: `1) 정기발송` → `2) 정기발송 시작` → `3) 정기발송 간격` → `4) 테스트 발송` 순서다. 번호는 `settings-plain-title`이 자동으로 붙이므로 제목 문자열에는 번호를 입력하지 않는다. 4번 설명은 다른 항목처럼 `최신 데이터로 즉시 1회 발송 테스트` 한 줄로 표시한다. 정기 설정과 관계없이 가장 최근 공통 스냅샷으로 홈 리포트를 즉시 한 번 보내며, 전송 전 확인을 받는다. 버튼 문구는 `테스트 발송 1회`이고, 설정창의 단일 동작 버튼과 같은 25px 높이·버튼 영역 전체 너비·13px 글자·4px 모서리 양식으로 둔다. 요청 중 비활성화하며 결과를 알린다.
- **메시지 발송 미리보기**: 샘플 카드는 가운데 정렬하고 최대 너비를 `max-w-2xl`로 제한한다. 좁은 화면에서는 가로폭에 맞춘다. 이미지 아래 왼쪽 요약 문구와 오른쪽 조회 수·시각 텍스트는 같은 글자 크기(`text-lg`)를 쓴다.
- **로컬 개발 화면 전용 계정 표시(운영에는 없다)**: `localhost`에서만 상단 오른쪽에 `ADMIN`·`TEST`·`GUEST` 배지를 보인다. GUEST일 때 프로필 칸을 누르면 운영처럼 메뉴 없이 바로 로그인 팝업이 열리고, 팝업의 Google 버튼이 관리자 계정으로 바로 로그인한다(로컬 서버에는 Google 로그인 설정이 없다). 로그아웃은 GUEST로 저장돼 새 탭에서도 유지된다. 테스트 계정 전환은 로그인한 뒤에만 보인다(ADMIN은 `테스트 계정으로 전환`, TEST는 `관리자 계정으로 전환`). 운영 화면은 이 표시 없이 기존 Google 로그인 흐름을 쓴다.
- 운영자 전용 설정창 탭의 항목도 공통 구조(`n) 헤더` → `- 설명` → 버튼 영역, 높이 180px, 첫 항목 위치는 다른 탭과 같은 y)를 따른다.
- **배너 문구 표시 한도**: 공지 입력과 붙여넣기는 상단 배너 미리보기의 실제 글꼴·너비·줄바꿈 범위까지만 허용한다. 편집 패널 안쪽 폭은 입력칸의 좌우 여백을 감안해 상단 미리보기와 실제 입력 줄 길이를 맞춘다. 줄바꿈도 표시 가능한 줄 수를 넘길 수 없다. 저장·게시·예약도 같은 한도를 확인한다.
- **게시 일정**: 패널 폭은 배너 내용 입력 패널과 맞춘다. 시작·종료 라벨은 15px 중간 굵기·22px 줄높이로 입력 컨트롤 위에 둔다. 종료 오른쪽의 `7일`·`14일`·`30일` 버튼은 시작 시각을 기준으로 같은 시각의 종료 일정을 정하며 기본은 30일이다. 버튼과 세 탭의 공통 전환 배지는 높이 25px로 맞춘다. 기간 버튼은 모두 같은 너비를 써 `7일`도 두 자리 기간과 폭을 맞춘다. 날짜·시각 배지와 기간 버튼 사이 간격은 줄이고, 일정 묶음은 패널이 좁아지면 겹치지 않게 다음 줄로 흐른다. 날짜와 시각은 각각 별도 배지로 표시하고 13px로 통일한다.
- 배너 화면 상단의 `목록`·`새 공지`·`새 광고` 전환 배지는 활성 상태를 같은 브랜드 청록으로 표시한다.
- 배너 화면 헤더는 목록에서 `목록`, 신규 작성에서 `새 공지`·`새 광고`, 기존 배너 편집에서 `공지 수정`·`광고 수정`을 제목으로 표시한다. 설명도 현재 작업에 맞춘다. 목록과 신규 작성에서는 해당 전환 배지를 강조하고, 기존 배너 편집에서는 세 배지 모두 선택되지 않은 상태로 둔다.
- 배너 설정 항목은 `1) 게시` → `2) 대기` → `3) 종료` → `4) 배너 전환 간격` 순서로 둔다. 각 목록은 제외 업종과 같은 92px 높이와 4개 행 표시를 쓰고, 내용이 넘칠 때만 스크롤바를 보이며 버튼 영역에 세로 여백을 둔다. 항목 전체 높이는 180px이다. 빈 목록 문구는 목록 행과 같은 13px로 버튼 영역 가운데에 둔다. 전환 간격은 게시 중인 배너에만 적용하고 공통 원형 다이얼로 5초부터 60초까지 5초 단위로 고른다. 다이얼은 조작하는 바늘·중심점을 초록색으로, 선택 부채꼴과 현재 값 배지는 중립 회색으로 표시한다. 저장·되돌리기는 설정창 상단 아이콘으로 제공하고, 누르기 전에는 서버값을 바꾸지 않는다. 메시지 발송 간격도 같은 다이얼을 쓰고 분 단위로 표시하며, 두 다이얼 모두 가운데 정렬하고 왼쪽에 현재 간격 배지를 둔다. 배지는 기존 20px 높이로 맞추고 고정 너비를 써 값이 바뀌어도 다이얼 위치를 유지한다. 메시지 간격은 임시값으로 조작한 뒤 설정창 상단의 저장·되돌리기로 반영한다. 기본 배너 간격은 10초다.
- 배너의 최종 동작인 `게시`·`예약`은 주요 버튼 규격에 따라 청록 바탕과 굵은 글자로 강조한다. 일반 저장·선택·취소 동작은 중립 회색을 유지한다.
- 배너 편집 화면은 `1) 미리 보기` → `2) 배너 내용` → `3) 게시 일정` 순서로 구성한다. 미리보기는 신규 배너와 기존 배너 수정 모두 입력에 따라 즉시 바뀐다. 배너 목록과 편집 미리보기는 공통 `BannerPreview`를 써서 크기·내용 렌더링을 맞춘다. 목록·편집 화면의 공통 제목과 전환 버튼은 고정하고, 구분선 아래 콘텐츠를 메인 영역에서 스크롤한다.
- 배너 편집 중 `목록` 또는 다른 종류로 이동할 때 저장하지 않은 수정이 있으면 `변경 내용 버리기`를 확인한다. 취소하면 편집을 유지하고, 확인하면 기존 배너는 저장된 내용으로 되돌리며 새 배너는 입력값을 비운다.

## 툴팁 규칙

마우스를 올리거나 키보드로 오면 뜨는 설명(툴팁·커서 툴팁)과, 눌러서 여는 설명(도움말)은 구분한다. 팝업과는 다른 종류다(팝업은 위 "팝업 규칙"). 박스를 우클릭하면 뜨는 창은 팝업이 아니라 "우클릭 메뉴"다.

| 종류 | 언제 뜨나 | 모양 | 코드 |
|---|---|---|---|
| **툴팁** | 마우스를 올림(0.15초 뒤)·키보드 포커스 | 말풍선색, 글자만 있음, 클릭 불가 | 요소에 `data-hint="설명"`을 단다(`HoverHintLayer`가 그림) |
| **커서 툴팁** | 지도 박스에 마우스를 올림, 마우스를 따라다님 | 말풍선색 | `Popup`의 `tooltip` 모드 |
| **도움말** | `?`를 눌러 엶 | 말풍선색 | `SettingHelpBubble`, `SourceHelpBubble` |

- 툴팁에는 브라우저 기본 `title` 속성을 쓰지 않는다. 항상 `data-hint`를 쓴다(운영자 관리 화면 포함).
- 글자 없이 아이콘만 있는 버튼은 `data-hint`와 함께 `aria-label`도 단다.
- 설명 문구는 짧게 `~기` 형태로 쓰고, 팝업 제목·버튼 이름과 같은 말투를 쓴다. 이동은 "돌아가기", 끌기는 "끌어서"로 통일한다.
- "말풍선"은 종류 이름으로 쓰지 않는다. 색 이름(말풍선색)으로만 남는다.
- 설정 설명(툴팁·도움말·제한 안내 등)에서 다른 설정 항목을 언급할 때는 **번호와 현재 항목명을 함께** 쓴다(예: `1-2) 업종 지표`). 참조 부분은 굵게 표시한다. 번호를 문자열에 직접 적지 말고 `settingNumber(항목 ID)`로 생성한다.
- 설정 탭·항목 순서나 명칭을 바꾸면 실제 표시 순서, `SETTINGS_SECTIONS`·`SETTING_ITEM_POSITIONS`와 관련 설명의 참조를 함께 확인하고 갱신한다. 이전 번호·명칭이 도움말에 남지 않게 한다.
- 홈은 종목 구성·색상, 그룹은 그래프·종목 구성·색상을 표시한다. 맵은 종목 구성·업종 분류·종목 박스·색상 순서다(2026-10-22 종목 구성을 맨 왼쪽으로 옮겼다). 공통 항목(시가총액 구간·업종 제외·등락률 색상·강조 색상)의 제목에만 청록색을 쓴다. 종목 등락 필터와 상위 업종 강조는 맵 전용이며, 그룹 집계는 항상 공통 시가총액 구간·제외 업종을 따른다. 그룹 그래프 설정은 유지하고 업종 클릭 시 맵으로 이동한다.
- 등락률 색상 임시값·편집 구간·되돌리기 기준은 홈·맵·그룹이 함께 사용한다. 페이지를 옮겨도 편집을 유지하며, 상단 저장·되돌리기에 함께 반영한다. 새로고침하면 저장값을 다시 읽고, 로그아웃·계정 전환 시 다른 계정의 임시 색상을 가져오지 않는다.
- 맵 설정의 색상 탭 순서: **4-1) 등락률 색상 → 4-2) 강조 색상 → 4-3) 상위 업종 강조**. 상위 업종 강조의 단계 제한은 **1-1) 업종 분류 깊이**, 순위 기준은 **1-2) 업종 지표**에 연결된다.
- 북마크 탭과 내부 설정 항목은 맵·관리자 설정창에서 모두 제거한다. 모든 설정 항목 헤더의 북마크 추가·해제 아이콘도 표시하지 않는다.
- 종목 정보의 열기 방식 설정은 지도 페이지 설정창의 **실험** 탭(예전 이름 `특별 회원`, 2026-10-23에 바꿈) 세 번째 항목이다. 이 탭은 특별 회원과 운영자만 보며, 탭 아이콘(플라스크 모양)과 항목 제목은 특별 회원 표시색(보라 `--sub-purple`)이다. 맵의 종목 박스 탭에는 박스 크기·박스 내 표기·등락률 소수점만 둔다. 종목 정보 설정은 기존 `heatmap.stockPopupOnHover` 키와 저장 방식, 지도에서의 우클릭·마우스 올리기 동작을 유지한다.

## 홈 틀 규칙

홈(Home) 메인 영역은 세 틀로 나뉜다. 기본 순서는 시장 요약, 요약 지도, 그룹 등락률이다. 사용자가 순서를 바꾸면 브라우저에 저장한다. 코드는 `MarketSummaryPage`의 `section` 세 개다. 틀의 바깥 모양은 아래로 정해졌고, 안쪽 내용은 나중에 추가·삭제한다.

- **구조**: 틀마다 [제목 줄 18px] + [본문]이다. 제목 줄은 지도 페이지의 섹터 헤더(높이 18px)와 같고, 본문은 제목 줄 바로 아래(간격 0)에서 시작해 지도 페이지의 첫 종목 박스와 같은 높이에 놓인다. 본문은 맨 아래 줄 바로 위까지 남는 높이를 모두 쓴다(세 틀 모두 같다).
- **크기**: 세 틀의 내용 폭은 같다(창 폭을 3으로 나누고 틀 사이 24px을 뺀 값. 사이드 영역이 열린 1600px 화면에서 417px, 1280px 화면에서 310px). 틀 최소 폭은 320px(시장 요약 틀의 지수·등락 종목·거래 대금 값 세 칸이 잘리지 않는 최소 폭)이고 더 좁으면 가로로 스크롤한다.
- **정렬**: 세 틀의 위쪽(툴바 아래 5.25px)과 아래쪽(맨 아래 줄 위)이 같고, 제목 줄과 본문의 시작선도 세 틀이 같은 높이에 있다. 틀 바깥 테두리와 틀 사이 구분선은 없다.
- **안쪽 여백**: 양 끝 틀의 바깥쪽은 0, 틀 사이(안쪽)는 12px씩이다. 여백은 틀이 아니라 틀 안쪽 칸에 둔다.
- **내용이 짧은 틀**: 본문이 모자라면 위에서부터 쌓고 남는 높이는 비운다(시장 요약 틀이 그렇다). 내용을 채울 때 틀 높이를 바꾸지 않는다.
- **글자·배지**: 틀 안 글자는 14px이고(그룹 등락률 그래프는 자리에 맞춰 10~16px로 커지고 줄어든다), 틀 제목은 회색(`gray-400`) 15px 굵은 소제목(지도 페이지 섹터 헤더와 같은 글자 크기, 왼쪽 4px 들여씀) + 오른쪽 얇은 구분선이다(제목 줄 18px 안에 세로 가운데). 배지는 모서리가 각진 직사각형이다.

## 아이콘 규칙

- 아이콘은 `src/components/icons/AppIcons.tsx`의 선 아이콘(24×24 격자, `stroke="currentColor"`, 끝·꺾임 둥글게)을 쓴다. 틀 없이 아이콘만 두는 것이 기본이다(상단 영역 버튼). 설정창 저장·되돌리기도 같다.
- **화면에 그려지는 선 굵기는 약 1.35px로 맞춘다.** 아이콘 크기가 다르면 선 값(`strokeWidth`)을 크기에 맞춰 준다: 16px는 2, 18px는 1.8, 20px는 1.6, 24px는 1.35, 15px는 2.1, 14px는 2.3. 계산은 `굵기 × 24 ÷ 크기`다. 도움말 `?`처럼 16 격자를 쓰는 인라인 아이콘은 `굵기 × 16 ÷ 크기`다(14px는 1.55, 11px는 1.95). 아이콘을 쓰는 곳에서 `strokeWidth`를 크기에 맞게 넘긴다.
- 눌러서 쓰는 아이콘 버튼(상단 영역의 스크린샷·전체화면·설정, 설정창의 저장·되돌리기)은 모두 **20px**이고 선은 약 1.35px(선 값 1.6)다. 설정창 저장·되돌리기는 기본 회색(`text-ui-muted`), 마우스 오버·키보드 포커스는 브랜드 청록이다. 스크린샷 아이콘은 Lucide `focus`(네 모서리 꺾쇠 안에 동그라미)이고 선 값은 1.6이다. 상단 세 버튼(스크린샷·전체화면·설정)의 그림은 20px 안에서 모두 **15px**로 보이게 맞춘다(전체화면 네모는 18칸, 설정은 격자를 21.33칸에 맞춰 선 값 1.44). 상단 버튼 폭은 28px, 설정창 저장·되돌리기 버튼 폭은 24px이고, 아이콘 사이 간격은 둘 다 8px이다.
- 켜진(열린) 상태는 색을 청록으로 바꾸고 안쪽을 35% 투명하게 채운다. 점선 아이콘(스크린샷)은 `filled` 속성으로 안쪽 사각형을 따로 채운다.
- 눌러서 쓰는 곳의 색은 평소 `gray-300`, 올리거나 켜면 청록이다.

## 표 정렬 규칙

Custom 표(종목·업종)의 칸 정렬은 값의 성격으로 정한다. 머리글은 모두 가운데다.

- **글자 수가 늘 같은 값**: 가운데 정렬한다(종목코드, 종목 크기, 마켓, NXT의 `O`/`-`).
- **길이가 달라지는 글자**: 왼쪽 정렬한다(업종명, 종목명, 약칭, 분류 이름).
- **크기가 달라지는 숫자**: 오른쪽 정렬한다(시가총액, 시가총액 합). 종목 수는 6글자 폭의 칸을 열 가운데에 두고 그 안에서 오른쪽 정렬해 자릿수가 달라도 끝이 맞는다(`CenteredRightNumber`).

## 괄호 규칙

화면 글자의 괄호는 안에 든 내용이 앞 말과 같은지 다른지로 띄어쓰기를 정한다.

- **앞 말과 같은 내용**(같은 뜻을 다시 풀거나 이름을 되풀이): 앞 글자에 **붙여** 쓴다. 예: `읽기 전용(쓰기 불가)`.
- **앞 말과 다른 내용**(조건·설명을 덧붙임): 앞 글자와 **띄어** 쓴다. 예: `NXT 거래 가능 종목 (키움증권 데이터가 없을 때만)`.

## 공통 로딩·오류 화면

- 로고가 있는 로딩·오류·정적 화면은 `Spinner` 하나를 공유한다. 원 안에 나무 심볼 → 회색 외곽선을 제거한 흰색 MARKETRY → 슬로건을 세로로 놓는다. 로딩 경과 숫자와 오류의 `다시 시도` 버튼은 같은 높이의 상태 칸을 공유해 로고 위치가 바뀌지 않는다.
- 원·로고·슬로건·숫자·버튼은 원 너비에 비례해 함께 확대·축소한다. 설정창과 캡처 팝업에서는 가용 폭·높이 중 작은 쪽을 기준으로 원 크기를 제한한다. 버튼 안의 작은 진행 표시는 기존 작은 링을 쓴다.
- 상단 로고 버튼(`NavBar`)은 기존 가로형 로고를 유지한다. 모바일 접속 안내(`MobileNotice`)는 세로형 로고와 `PC 화면에 최적화되어 있습니다.` 문구를 표시하며, 안내 글자 크기는 기존 PC 접속 안내 제목과 같은 `text-lg`를 쓴다. 어드민 메인은 공통 로고를 정적으로 표시하며, 로고 아래 공통 상태 칸에 빨간 ⚠ 아이콘을 둔다.
