# 화면 영역 이름

화면 위치는 **바탕색으로 구분한 세 영역**의 이름으로 부른다. 지시는 "영역 > 위치"로 쓴다.
예: "상단 영역 오른쪽 끝의 스크린샷 버튼", "메인 영역 > 맨 아래 줄 > 범례", "사이드 영역 > 맨 아래 > Basis".

| 영역 | 바탕색 | 화면 위치 | 코드 |
|---|---|---|---|
| **상단 영역** | `#1a1a1a` (어두운 중립 회색) | 맨 위. 로고 줄, Home · Map · Graph · Custom 메뉴 줄(글자 앞에 설정창과 같은 아이콘), 오른쪽 끝 버튼(스크린샷·전체 화면·설정) | `NavBar`, `NavSubBar` |
| **메인 영역** | `#0a0a0a` (거의 검정) | 가운데. 페이지마다 다르다(Map은 트리맵, Graph는 막대 그래프, Custom은 표). 화면 스크린샷은 메인 영역만 찍는다. | `src/pages/MapPage.tsx`, `GroupPage.tsx`, `CustomPage.tsx` |
| **사이드 영역** (설정창) | `#2a2a2a` (중립 회색) | 옆에 붙은 설정 영역. 왼쪽으로 옮길 수 있어서 "오른쪽"이라 부르지 않는다. 접을 수도 있다. | `SettingsPanel` |

- 영역을 구분할 때는 바탕색을 기준으로 한다. 색이 같은 줄은 같은 영역이다.
- 홈·맵·그룹·커스텀·운영 페이지는 메인·설정창의 바깥 좌우 여백과 두 영역 사이 간격을 각각 4px로 맞춘다. 설정창을 왼쪽으로 옮겨도 같으며, 접으면 사이 간격을 없앤다. 여백은 `main-settings-row`에서 관리하고 툴바·본문·아래 줄에 중복으로 넣지 않는다.
- **헤더**는 영역 이름이 아니다. 각 영역·표의 맨 윗줄을 가리키는 말이라 항상 앞에 붙여 쓴다: "설정창 헤더"(사이드 영역 맨 윗줄), "표 헤더"(열 머리글).
- 세 영역 밖의 것은 건드리지 않는다. 지시한 영역에서 벗어난 파일을 고쳐야 하면 먼저 알린다.
- Home 같은 페이지에는 사이드 영역이 없다.

- 설정창은 상단 영역 아래에서 4px 띄운다. 헤더는 윗선을 기존보다 3px 올리되 아래 구분선은 유지한다. 헤더 위아래 패딩은 각각 11.75px로 같게 두어 제목·종목 수·버튼을 세로 중간에 맞추고, 탭 메뉴와 설정 본문은 그 아래에 이어진다.
- 설정창 하단은 화면 아래에서 4px 띄운다. 하단 Basis 영역의 아래 패딩을 4px 줄여 확보하며 설정 본문 높이는 유지한다.
- 메인 툴바 배지·칩·검색창은 기본 24px에서 아래쪽으로만 2.25px 늘린 26.25px 높이다. `main-toolbar` 안의 `toolbar-badge`는 음수 아래 여백으로 윗선과 주변 배치를 유지하고, 내부 버튼은 `toolbar-badge-control`로 높이를 맞춘다.
- 설정창 선택 버튼·시가총액 범위 배지·Basis 버튼·작은 업종명 배지는 라운딩 4px로 맞춘다. 메인 툴바 분류 배지는 직각, 설정창 외곽은 6px다.
- 홈의 세 항목 제목은 각 항목 왼쪽에 놓고 오른쪽으로 구분선을 잇는다. 제목 글자색은 지도 설정의 강조 색상을 따르며, 배지는 지도 대분류와 같은 흰색 18% 배경·3px 라운딩·좌우 4px 패딩을 쓴다.
- **설정 항목의 공통 구조(새 항목에도 필수 적용)**: `n) 헤더` → `- 설명 문구` → 그 아래 남은 **버튼 영역** 순서로 구성한다. 이 세 부분을 합친 한 항목의 전체 높이는 **180px**다. 버튼·슬라이더·입력창 등 조작부 묶음은 버튼 영역의 세로 중간에 둔다. 항목 사이는 공통 구분선으로 나눈다. 페이지나 기능별로 별도 프레임·고정 간격을 만들지 않고 공통 설정창 구조와 정렬 규칙을 사용한다.
- 모든 페이지 설정창의 각 항목 높이는 첫 항목을 포함해 180px로 통일한다. 각 항목 제목은 기존보다 4px 아래에 둔다. 본문 상단 여백 12px는 항목 높이와 별도로 둔다. 목록은 항목 내부에서 스크롤하고, 조작부는 제목·설명 아래 남은 공간의 세로 중간에 둔다. 홈·그룹·커스텀·어드민의 버튼·슬라이더·입력부 묶음을 제목·설명 하단과 항목 아래 구분선 사이의 세로 중간에 맞춘다(구분선은 다음 제목 12px 위). 맵도 조작부 묶음의 실제 높이를 기준으로 남은 공간을 위아래로 나누며, 항목 위치를 맞추기 위한 9.5px·7.5px 같은 고정 위 여백은 쓰지 않는다. 업종 지표 선택 줄과 예시 그림, 박스 크기 아이콘·트랙·라벨은 각각 한 묶음으로 정렬한다.
- 모든 페이지 설정창은 항목 사이와 마지막 항목 아래에 같은 구분선(흰색 12%, 1px)을 표시한다. 맵·어드민과 단일 탭 안에 항목을 쌓는 홈·그룹·커스텀에 공통으로 적용한다. 읽기 전용 안내는 동일한 180px 영역 안에 가로 가운데·세로 중간 정렬하고 구분선을 표시하지 않는다.
- 설정창 메뉴 줄은 모든 페이지에서 높이 68px로 맞춘다. 홈은 `종목 구성 → 색상`, Graph는 `그래프 → 종목 구성 → 색상`, 커스텀은 종목·업종 화면 모두 `커스텀` 단일 탭을 표시한다. 커스텀은 직접 자유롭게 만든다는 뜻의 손그림 선·펜 아이콘을 쓴다. MARKETRY·거래소의 설정 본문은 첫 항목 높이인 180px 안에 번호 없이 `읽기 전용`과 `내 분류만 가능`을 두 줄로 가로 가운데·세로 중간에 표시한다. 이름과 선택 밑줄은 맵·어드민과 같은 높이에 둔다. 홈의 `요약 지도`, `그룹 등락률 (%)`, `시장 요약`은 제목을 잡고 가로로 끌어 배치하며, 순서는 브라우저에 저장한다. 홈 캡처 팝업에는 전체 캡처와 현재 좌측·중앙·우측 항목별 캡처 버튼을 둔다. 맵 캡처 팝업에는 모니터·모바일 영역 선택을 둔다. 전체 화면 캡처는 좌우 4px 여백을 포함한다. 모바일 캡처는 화면 높이를 기준으로 세로 4:3 프레임을 만들고, 좌우·위쪽은 4px 프레임 여백을 둔다. 하단은 프레임 높이만 줄여 맞추지 않는다. 실제 캡처 결과에서 하단을 4 CSS px 더 잘라 여백을 맞춘다.
- 설정창에서 마지막으로 고른 탭은 페이지별로 브라우저에 저장한다. 다시 열거나 새로고침해도 복원하고, 현재 계정에서 사용할 수 없는 탭은 첫 번째 탭을 표시한다.
- 상단 영역의 캡처 버튼 왼쪽에는 안쪽으로 감기는 소용돌이 화살표 아이콘의 브라우저 저장값 초기화 버튼을 둔다. 확인하면 이 사이트의 `localStorage`와 `sessionStorage`를 모두 비우고 새로고침한다. 이후 같은 브라우저 저장소에 추가한 기능도 함께 초기화한다. 서버 저장값과 로그인 쿠키는 지우지 않는다.
- 브라우저 저장값 초기화 확인창은 초기화 질문 아래에 설정창 위치·설정 탭 선택·캡처창 선택을 회색 예시로 보여 주고, 그다음 줄에 서버 저장값은 유지된다고 알린다.
- 커스텀 업종 화면 설정창은 `1) 업종 추가 → 2) 변경 내역` 순서로 둔다. 상하 관계 이동은 업종 목록의 번호 배지를 끌어 대상 행의 `여기`에 놓는 방식으로만 시작하고, 별도의 `업종 재배치` 항목이나 이동 안내 팝업은 두지 않는다. 허용되는 대상 행과 최상위 헤더에는 드래그 중에만 `여기`를 표시한다. 번호 배지 이동은 포인터 위치로 대상 행을 판정하고, 왼쪽 손잡이는 기존처럼 같은 열 안에서 순서를 바꾼다.
- 하위 업종 추가 입력은 성공하면 닫고, 실패하면 입력한 이름을 유지한다. 연속으로 더 추가하려면 대상 행의 `+`를 다시 눌러 입력을 연다. 생성되거나 이동한 업종은 행 배경색으로 표시하고 화면 안으로 스크롤한다.
- 설정창 슬라이더 아래 눈금은 트랙과 4px 간격을 두고, 보통 13px 글자를 쓴다. 선택된 눈금은 흰색·중간 굵기, 나머지는 흐린색·기본 굵기다. 등락률 색상 편집 막대는 눈금 사이가 좁아 12px, 선택값 배지는 11px로 둔다.
- 제외 업종 목록은 한 번에 4개(각 20px, 사이 4px)가 보이고, 더 많으면 목록 안에서 스크롤한다.

### 모바일 지도 캡처 회귀 방지

- 모바일 전용 복제 레이아웃은 `MapPage.tsx`의 `[data-map-mobile-capture-frame]` 안에만 둔다. `revealMobileCapture`는 스크린샷 복제본의 툴바만 다시 구성하므로, 모바일 정렬을 고칠 때 실제 지도 툴바나 `main-settings-row`의 크기·위치를 바꾸지 않는다.
- 복제 툴바의 기준 배치는 한 줄이다: 좌측에 ALL STOCK·날짜·시계/시간·세션, 그 다음 등락률 기준 버튼 하나를 둔다. 우측 끝에는 분류 배지를 둔다. MAP 라벨은 숨기며, 복제 시계는 새로고침 아이콘으로 바뀌지 않도록 고정한다. 등락률 버튼은 선택된 기준명만 보라색 배경의 정적 칩으로 복제하며 메뉴는 열리지 않는다. 칩 높이는 26.25px로 유지한다.
- 하단 여백은 `screenshotToPreview.ts`에서 모바일 캡처 이미지의 마지막 4 CSS px를 직접 잘라 맞춘다. 투명/배경색 행 탐지에 의존하지 않는다. 프레임의 `height`·하단 패딩을 조절하면 트리맵의 실제 배치와 캡처 범위가 함께 바뀌어 지도 잘림·빈 띠를 다시 만들 수 있으므로, 여백 수정은 이 이미지 후처리 경로를 기준으로 한다.
- 레이아웃을 바꾼 뒤 Orca의 스크린샷 팝업에서 모니터를 한 번 선택한 다음 모바일을 다시 선택해 새 이미지를 만든다. 하단 여백이 좌우 4px와 비슷한지, 마지막 타일이 잘리지 않았는지, 상단 툴바가 한 줄인지, 선택된 등락률 버튼과 우측 분류 배지가 제자리에 있는지 확인한다. 미리보기만 보고 끝내지 말고 실제 복사 이미지에도 같은 후처리가 적용되는지 확인한다.

- **업종 단계 이름**: 깊이 순서대로 대분류 · 중분류 · 소분류 · 세분류. 지금은 3단계(대·중·소분류)만 쓰고, 4단계(세분류)는 이름만 정해 뒀고 거의 만들지 않을 예정이다(거래소 새 업종 분류 발표를 보고 최종 정한다). 5단계 이상은 지도 위에서 자리가 모자라 만들지 않는다. 이동 경로 툴팁이 이 이름을 쓴다(`대분류로 돌아가기`).
- 화면의 **Basis**(설정창 맨 아래)는 코드에서 `Taxonomy`(분류 선택)다. 코드의 `basis`는 이것이 아니라 일간/시간외 등락률 기준이며, 서버에 보내는 요청 항목 이름(`basis=afterHours`)으로만 남아 있고 코드 안에서는 `ChangeRateMode`라고 부른다.
- "히트맵", "콤보박스"라는 말은 화면과 코드에서 쓰지 않는다. 드롭다운이라고 부른다.
- **업종 / 거래소 분류**: 화면의 "업종"은 우리 분류의 한 덩어리(대·중·소분류 어느 단계든, 영어 `Sector`)이고, 종목 표의 "거래소 분류"은 거래소(키움 `upName`)가 정한 업종(코드 `industry`)이다. 화면 영어는 `Sector`만 쓰고 `Industry`는 쓰지 않는다. Custom 페이지 주소는 `/custom/sector`(옛 `/custom/industry`는 새 주소로 보낸다)와 `/custom/stock`이다.
- 분류 갱신 시각 필드는 `taxonomyUpdatedAt`이다. 서버는 한동안 옛 이름 `classificationUpdatedAt`도 같이 보내며, 화면 전환이 끝난 뒤 서버에서 옛 이름을 지운다.

## 뜨는 것 찾는 법 (동작으로 구분)

이름이 헷갈리면 "내가 뭘 했더니 뭐가 떴는지"로 찾는다. 사용자가 위치·모양으로 설명하면 아래 표로 해당 이름을 찾아 해석한다.

| 내가 한 동작 | 뜨는 것 | 뒤 화면 | 아래 항목 |
|---|---|---|---|
| 버튼을 눌렀더니 화면이 어두워지며 창이 뜸 | **팝업** (확인창·알림창·스크린샷 창) | 어두워지고 클릭 막힘 | 팝업 규칙 |
| 상황이 생겨서 창이 뜸, 배경은 그대로 | **팝업** (안내창) | 그대로, 클릭 가능 | 팝업 규칙 |
| 마우스를 올림 | **툴팁** | 그대로 | 툴팁 규칙 |
| 박스를 우클릭 | **우클릭 메뉴** | 그대로 | 영역별 화면 요소 |
| `?`를 누름 | **도움말** | 그대로 | 툴팁 규칙 |

## 팝업 규칙

팝업은 **확인창**·**안내창**·**알림창**으로 나눈다(이름은 임시). 안내창은 지나가도 되는 알림이고, 알림창은 꼭 읽고 닫아야 하는 알림이다. 새 팝업을 만들 때 먼저 어느 쪽인지 정한다. "확인 팝업 띄워", "안내 팝업 띄워"는 각 종류를 화면에 띄워 달라는 뜻이다.

| 종류 | 배지 | 배경 | 클릭 | 예 | 코드 |
|---|---|---|---|---|---|
| **확인창** (사용자가 확인·취소로 답해야 함) | 청록 "확인" | 화면 전체를 어둡게 덮음 | 뒤 화면 클릭을 막음 | 저장하기·되돌리기 확인 | `AppDialogHost` |
| **안내창** (알림만) | 앰버 "안내" | 배경 없음 | 뒤 화면을 계속 쓸 수 있음 | 지도의 NXT 안내 | `MapPage`의 NXT 공지 |
| **알림창** (확인만 누르면 됨) | 호박색 "알림" | 화면 전체를 어둡게 덮음 | 뒤 화면 클릭을 막음 | 저장 실패 | `AppDialogHost`(`appAlert`) |

- **알림창 제목은 "동작 + 결과"로 쓴다**: `적용 완료`·`적용 실패`, `일괄 변경 완료`·`일괄 변경 실패`, `업데이트 완료`·`업데이트 실패`, `롤백 완료`·`롤백 실패`, `저장 실패`, `불러오기 실패`, `삭제 실패`, `이동 실패`처럼 결과가 제목에 드러나게 한다. 막혀서 못 하는 경우는 `추가 제한`·`삭제 불가`·`이동 제한`·`요청 실패`, 바뀐 것이 없으면 `적용 없음`이다. 확인창 제목은 결과가 없으므로 "대상 + 동작"(`업종 삭제`, `버전 불러오기`)이다.
- **확인창 본문 모양**: 대상이 있으면 첫 줄에 `[대상]`만 쓰고(조사·종류 낱말 없이), 둘째 줄에 동작(`~하시겠습니까?`), 덧붙임은 셋째 줄부터 쓴다(예: `[반도체]` / `삭제하시겠습니까?` / `하위 업종 …`). 대상은 업종명 또는 버전 시각이다. 대상 이름이 없는 문장(색상 초기화, 저장하기 등)은 한 줄이다. 동사는 `업데이트하시겠습니까?`처럼 명사와 붙여 쓴다(`업데이트하다`가 한 낱말이라 띄우면 맞춤법 오류다).
- **오류·빈 화면 문구**: 모두 문장이라 마침표로 끝낸다. 하려던 동작이 실패했을 때는 `~하지 못했습니다.`(예: `저장하지 못했습니다.`), 원래부터 안 되는 것은 `~할 수 없습니다.`(예: `삭제할 수 없습니다.`)다. 다시 해 볼 만한 실패 뒤에는 `잠시 후 다시 시도해 주세요.`를 붙인다. 빈 목록은 `검색 결과가 없습니다.`·`표시할 데이터가 없습니다.`처럼 `~가 없습니다.`로 쓴다(`결과가 없습니다` 같은 짧은 줄임말은 쓰지 않는다).
- **본문에 업종명이나 버전 시각을 쓸 때는 `[ ]`로 감싸 첫 줄에 `[이름]`만 적고 다음 줄에 내용을 적는다**(확인창·알림창 모두 같다. 예: `[반도체]` / `일괄 적용 완료되었습니다.`, `[2026-10-13 18:42]` / `불러오시겠습니까?`). 종목 이름과 일반 수는 감싸지 않는다.
- 제목 앞에 종류 배지(`PopupKindBadge`)를 붙이고, 배지 오른쪽에 제목을 적는다. 확인창 제목은 짧게 "대상 + 동작"으로 쓴다(예: "업종 삭제", "버전 불러오기", "색상 초기화"). 대상이 분명한 설정창 저장·되돌리기는 "저장하기", "되돌리기"로 쓴다. 툴팁 문구("저장값으로 되돌리기", "변경값으로 저장하기")보다 간결하다. 제목은 `appConfirm(message, { title })`로 넘긴다.
- 공통 양식: 말풍선색 창, 굵은 제목, 오른쪽 아래 청록 닫기 버튼.
- 확인창·알림창·NXT 안내창·로그인 팝업의 가로 중심은 메인 영역(`data-main-area`), 세로 중심은 전체 화면을 기준으로 맞춘다. 업데이트·롤백 로딩 원의 위치는 이 규칙에 포함하지 않는다.
- 크기: 확인창·알림창·안내창은 폭 384px(`max-w-sm`), 높이 198px로 통일한다(본문 3줄 기준, `POPUP_SIZE_CLASS`). 본문이 3줄을 넘으면 줄 수만큼 높이를 늘린다. 버튼 줄은 항상 맨 아래에 붙고, 본문과의 간격은 12px이다.
- 안내창은 공유 이미지에 담지 않는다(`data-capture-ignore`).
- **스크린샷 창**: 상단 영역의 스크린샷 버튼(점선 사각형 아이콘)을 누르면 뜨는 메인 영역 스크린샷 미리보기 창(다운로드·클립보드·닫기). 확인창·안내창과 별개의 종류이고, 코드 이름은 `ScreenshotModal`이다.

## 운영자 전용 표시

운영자만 쓰는 것은 일부러 일반 규칙(한글·청록)에서 벗어나 **눈에 띄게** 만든다. 이것이 유일하게 허용하는 예외다.

- Custom 페이지 설정창의 `⚠ ADMIN` 띠와 `UPDATE`·`ROLLBACK` 버튼은 영어 대문자·빨간색이다(MARKETRY 맵을 바꾸는 작업이라 실수로 누르지 않게 튀게 둔다). 롤백 목록 줄은 `[시각]`만 보여 주고, 알림창·확인창 제목은 한글("업데이트 완료", "롤백 완료")이다.
- 운영자 전용 표시 색은 골드(`--admin-only`, 올림·선택은 밝힌 `--admin-only-hover`) 하나다. 상단 Admin 메뉴, 설정창 관리자 탭과 제목, 프로필 팝업의 ADMIN 전환 버튼(TEST·GUEST 버튼과 배지는 중립 회색), 운영자 확인창(테두리·제목·버튼)에 쓴다.
- 운영자 전용 설정창 탭의 항목도 공통 구조(`n) 헤더` → `- 설명` → 버튼 영역, 높이 180px, 첫 항목 위치는 다른 탭과 같은 y)를 따른다.

## 툴팁 규칙

마우스를 올리거나 키보드로 오면 뜨는 설명(툴팁·커서 툴팁)과, 눌러서 여는 설명(도움말)은 구분한다. 팝업과는 다른 종류다(팝업은 위 "팝업 규칙"). 박스를 우클릭하면 뜨는 창은 팝업이 아니라 "우클릭 메뉴"다.

| 종류 | 언제 뜨나 | 모양 | 코드 |
|---|---|---|---|
| **툴팁** | 마우스를 올림(0.15초 뒤)·키보드 포커스 | 말풍선색, 글자만 있음, 클릭 불가 | 요소에 `data-hint="설명"`을 단다(`HoverHintLayer`가 그림) |
| **커서 툴팁** | 지도 박스에 마우스를 올림, 마우스를 따라다님 | 말풍선색 | `Popup`의 `tooltip` 모드 |
| **도움말** | `?`를 눌러 엶 | 말풍선색 | `SettingHelpBubble`, `SourceHelpBubble` |

- 툴팁에는 브라우저 기본 `title` 속성을 쓰지 않는다. 항상 `data-hint`를 쓴다(운영자 관리 화면 포함).
- 글자 없이 아이콘만 있는 버튼은 `data-hint`와 함께 `aria-label`도 단다.
- 설명 문구는 짧게 `~기` 형태로 쓰고, 팝업 제목·버튼 이름과 같은 말투를 쓴다. 이동은 "돌아가기", 끌기는 "끌어서"로 통일한다.
- "말풍선"은 종류 이름으로 쓰지 않는다. 색 이름(말풍선색)으로만 남는다.
- 설정 설명(툴팁·도움말·제한 안내 등)에서 다른 설정 항목을 언급할 때는 **번호와 현재 항목명을 함께** 쓴다(예: `1-2) 업종 지표`). 참조 부분은 굵게 표시한다. 번호를 문자열에 직접 적지 말고 `settingNumber(항목 ID)`로 생성한다.
- 설정 탭·항목 순서나 명칭을 바꾸면 실제 표시 순서, `SETTINGS_SECTIONS`·`SETTING_ITEM_POSITIONS`와 관련 설명의 참조를 함께 확인하고 갱신한다. 이전 번호·명칭이 도움말에 남지 않게 한다.
- 홈은 종목 구성·색상, 그룹은 그래프·종목 구성·색상을 표시한다. 맵은 종목 구성·업종 분류·종목 박스·색상 순서다(2026-10-22 종목 구성을 맨 왼쪽으로 옮겼다). 공통 항목(시가총액 구간·업종 제외·등락률 색상·강조 색상)의 제목에만 청록색을 쓴다. 종목 등락 필터와 상위 업종 강조는 맵 전용이며, 그룹 집계는 항상 공통 시가총액 구간·제외 업종을 따른다. 그룹 그래프 설정은 유지하고 업종 클릭 시 맵으로 이동한다.
- 등락률 색상 임시값·편집 구간·되돌리기 기준은 홈·맵·그룹이 함께 사용한다. 페이지를 옮겨도 편집을 유지하며, 상단 저장·되돌리기에 함께 반영한다. 새로고침하면 저장값을 다시 읽고, 로그아웃·계정 전환 시 다른 계정의 임시 색상을 가져오지 않는다.
- 맵 설정의 색상 탭 순서: **4-1) 등락률 색상 → 4-2) 강조 색상 → 4-3) 상위 업종 강조**. 상위 업종 강조의 단계 제한은 **1-1) 업종 분류 깊이**, 순위 기준은 **1-2) 업종 지표**에 연결된다.
- 북마크 탭과 내부 설정 항목은 맵·관리자 설정창에서 모두 제거한다. 모든 설정 항목 헤더의 북마크 추가·해제 아이콘도 표시하지 않는다.
- 종목 정보의 열기 방식 설정은 지도 페이지 설정창의 **실험** 탭(예전 이름 `특별 회원`, 2026-10-23에 바꿈) 세 번째 항목이다. 이 탭은 특별 회원과 운영자만 보며, 탭 아이콘(플라스크 모양)과 항목 제목은 특별 회원 표시색(보라 `--sub-purple`)이다. 맵의 종목 박스 탭에는 박스 크기·박스 내 표기·등락률 소수점만 둔다. 종목 정보 설정은 기존 `treemap.stockPopupOnHover` 키와 저장 방식, 지도에서의 우클릭·마우스 올리기 동작을 유지한다.

## 홈 틀 규칙

홈(Home) 메인 영역은 세 틀로 나뉜다. 기본 순서는 시장 요약, 요약 지도, 그룹 등락률이다. 사용자가 순서를 바꾸면 브라우저에 저장한다. 코드는 `MarketSummaryPage`의 `section` 세 개다. 틀의 바깥 모양은 아래로 정해졌고, 안쪽 내용은 나중에 추가·삭제한다.

- **구조**: 틀마다 [제목 줄 18px] + [본문]이다. 제목 줄은 지도 페이지의 섹터 헤더(높이 18px)와 같고, 본문은 제목 줄 바로 아래(간격 0)에서 시작해 지도 페이지의 첫 종목 박스와 같은 높이에 놓인다. 본문은 맨 아래 줄 바로 위까지 남는 높이를 모두 쓴다(세 틀 모두 같다).
- **크기**: 세 틀의 내용 폭은 같다(창 폭을 3으로 나누고 틀 사이 24px을 뺀 값. 사이드 영역이 열린 1600px 화면에서 417px, 1280px 화면에서 310px). 틀 최소 폭은 320px(시장 요약 틀의 지수·등락 종목·거래 대금 값 세 칸이 잘리지 않는 최소 폭)이고 더 좁으면 가로로 스크롤한다.
- **정렬**: 세 틀의 위쪽(툴바 아래 5.25px)과 아래쪽(맨 아래 줄 위)이 같고, 제목 줄과 본문의 시작선도 세 틀이 같은 높이에 있다. 틀 바깥 테두리와 틀 사이 구분선은 없다.
- **안쪽 여백**: 양 끝 틀의 바깥쪽은 0, 틀 사이(안쪽)는 12px씩이다. 여백은 틀이 아니라 틀 안쪽 칸에 둔다.
- **내용이 짧은 틀**: 본문이 모자라면 위에서부터 쌓고 남는 높이는 비운다(시장 요약 틀이 그렇다). 내용을 채울 때 틀 높이를 바꾸지 않는다.
- **글자·배지**: 틀 안 글자는 14px이고(그룹 등락률 그래프는 자리에 맞춰 10~16px로 커지고 줄어든다), 틀 제목은 회색(`gray-400`) 15px 굵은 소제목(지도 페이지 섹터 헤더와 같은 글자 크기, 왼쪽 4px 들여씀) + 오른쪽 얇은 구분선이다(제목 줄 18px 안에 세로 가운데). 배지는 모서리가 각진 직사각형이다.

## 아이콘 규칙

- 아이콘은 `src/components/icons/AppIcons.tsx`의 선 아이콘(24×24 격자, `stroke="currentColor"`, 끝·꺾임 둥글게)을 쓴다. 틀 없이 아이콘만 두는 것이 기본이다(상단 영역 버튼). 설정창 저장·되돌리기도 같다.
- **화면에 그려지는 선 굵기는 약 1.35px로 맞춘다.** 아이콘 크기가 다르면 선 값(`strokeWidth`)을 크기에 맞춰 준다: 16px는 2, 18px는 1.8, 20px는 1.6, 24px는 1.35, 15px는 2.1, 14px는 2.3. 계산은 `굵기 × 24 ÷ 크기`다. 도움말 `?`처럼 16 격자를 쓰는 인라인 아이콘은 `굵기 × 16 ÷ 크기`다(14px는 1.55, 11px는 1.95). 아이콘을 쓰는 곳에서 `strokeWidth`를 크기에 맞게 넘긴다.
- 눌러서 쓰는 아이콘 버튼(상단 영역의 스크린샷·전체화면·설정, 설정창의 저장·되돌리기)은 모두 **20px**이고 선은 약 1.35px(선 값 1.6)다. 스크린샷 아이콘은 Lucide `focus`(네 모서리 꺾쇠 안에 동그라미)이고 선 값은 1.6이다. 상단 세 버튼(스크린샷·전체화면·설정)의 그림은 20px 안에서 모두 **15px**로 보이게 맞춘다(전체화면 네모는 18칸, 설정은 격자를 21.33칸에 맞춰 선 값 1.44). 상단 버튼 폭은 28px, 설정창 저장·되돌리기 버튼 폭은 24px이고, 아이콘 사이 간격은 둘 다 8px이다.
- 켜진(열린) 상태는 색을 청록으로 바꾸고 안쪽을 35% 투명하게 채운다. 점선 아이콘(스크린샷)은 `filled` 속성으로 안쪽 사각형을 따로 채운다.
- 눌러서 쓰는 곳의 색은 평소 `gray-300`, 올리거나 켜면 청록이다.

## 표 정렬 규칙

Custom 표(종목·업종)의 칸 정렬은 값의 성격으로 정한다. 머리글은 모두 가운데다.

- **글자 수가 늘 같은 값**: 가운데 정렬한다(종목코드, 종목 크기, 마켓, NXT의 `O`/`-`).
- **길이가 달라지는 글자**: 왼쪽 정렬한다(업종명, 종목명, 약칭, 분류 이름).
- **크기가 달라지는 숫자**: 오른쪽 정렬한다(시가총액, 시가총액 합). 종목 수는 6글자 폭의 칸을 열 가운데에 두고 그 안에서 오른쪽 정렬해 자릿수가 달라도 끝이 맞는다(`CenteredRightNumber`).

## 괄호 규칙

화면 글자의 괄호는 안에 든 내용이 앞 말과 같은지 다른지로 띄어쓰기를 정한다.

- **앞 말과 같은 내용**(같은 뜻을 다시 풀거나 이름을 되풀이): 앞 글자에 **붙여** 쓴다. 예: `읽기 전용(쓰기 불가)`.
- **앞 말과 다른 내용**(조건·설명을 덧붙임): 앞 글자와 **띄어** 쓴다. 예: `NXT 거래 가능 종목 (키움증권 데이터가 없을 때만)`.

## 공통 로딩·오류 화면

- 로고가 있는 로딩·오류·정적 화면은 `Spinner` 하나를 공유한다. 원 안에 나무 심볼 → 회색 외곽선을 제거한 흰색 MARKETRY → 슬로건을 세로로 놓는다. 로딩 경과 숫자와 오류의 `다시 시도` 버튼은 같은 높이의 상태 칸을 공유해 로고 위치가 바뀌지 않는다.
- 원·로고·슬로건·숫자·버튼은 원 너비에 비례해 함께 확대·축소한다. 설정창과 캡처 팝업에서는 가용 폭·높이 중 작은 쪽을 기준으로 원 크기를 제한한다. 버튼 안의 작은 진행 표시는 기존 작은 링을 쓴다.
- 상단 로고 버튼(`NavBar`)은 기존 가로형 로고를 유지한다. 모바일 접속 안내(`MobileNotice`)는 세로형 로고와 `현재 페이지는 PC 화면에 최적화되어 있습니다.` 문구를 표시하며, 안내 글자 크기는 기존 PC 접속 안내 제목과 같은 `text-lg`를 쓴다. 어드민 메인은 공통 로고를 정적으로 표시하며, 로고 아래 공통 상태 칸에 빨간 ⚠ 아이콘을 둔다.
