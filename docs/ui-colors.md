# UI 색상 규칙

## 통합 계획과 적용

1. 지도·그래프의 데이터 색, 강조 색상 선택지, 거래 세션 점, 외부 로고는 분리한다.
2. 사이트 UI의 회색·파랑 계열 중복을 배경·표면·패널·테두리·글자 역할에 맞춰 합친다.
3. 오류·경고·관리자 주의 표시는 테라코타 원색 하나를 공유하고 성공은 메인 청록을 공유한다.
4. 호버·선택·비활성은 기본색의 혼합·투명도·opacity로 표현한다.
5. 기본색 수, 데이터 팔레트 보존, 주요 글자 대비, 린트·빌드, 실제 화면을 확인한다.

## 기본색 14개

원색 정의는 `src/index.css`의 `:root`에 모은다. Tailwind에서는 같은 파일의 `@theme inline`에 등록한 역할 이름을 사용한다.

| 구분 | 변수 | HEX | 역할 |
|---|---|---|---|
| 브랜드 | `--brand` | `#12B8A6` | 선택 메뉴·강조·아이콘 |
| 브랜드 | `--brand-surface` | `#20635D` | 주요 버튼·배지 배경 |
| 서브 | `--secondary` | `#46597D` | 서브 팔레트 어두운 단계 |
| 서브 | `--secondary-soft` | `#798BB2` | 애프터 마켓 표시·Admin 탐색 링크 |
| 무채색 | `--ui-background` | `#000000` | 메인 영역·어두운 오버레이·팝업 글자 |
| 무채색 | `--ui-surface` | `#0F1414` | 상단 영역·표면·밝은 선택 영역의 글자 |
| 무채색 | `--ui-panel` | `#212828` | 설정창·필터·표 헤더·입력창 |
| 무채색 | `--ui-border` | `#4B5563` | 테두리·비활성 트랙 |
| 무채색 | `--ui-text` | `#E2E4EF` | 본문 글자 |
| 무채색 | `--ui-muted` | `#9CA3AF` | 보조 글자 |
| 무채색 | `--ui-white` | `#FFFFFF` | 흰 글자·아이콘·혼합 기준 |
| 팝업 | `--ui-popup` | `#FFF8E7` | 크림 바탕 |
| 팝업 | `--ui-popup-border` | `#7A6D55` | 팝업·도움말 테두리 |
| 상태 | `--status-error` | `#C47B5A` | 오류·삭제·관리자·알림의 테라코타 원색 |

성공 메시지의 `--status-success`는 `--brand`의 별칭이다. 별도 원색을 정의하지 않는다.

알림 배지의 `--status-warning`은 흰 글자 대비를 위해 `--status-error-ink`를 공유한다. 웜 골드 `#D6A45A`는 추천·특별 표시용 후보로 보류하며 현재 UI 팔레트에는 추가하지 않는다.

## 원색을 추가하지 않는 파생색

- `--ui-control`: 패널 80% + 흰색 20%. 선택 전 칩·일반 버튼.
- `--ui-control-hover`: 패널 65% + 흰색 35%. 일반 조작부 호버.
- `--ui-selection`: 흰색 80% + 패널 20%. 선택 영역·취소 버튼·슬라이더 선택 트랙.
- `--brand-surface-hover`: 서브 80% + 메인 20%.
- `--brand-surface-dark`: 서브 80% + 검정 20%.
- `--status-error-text`: 테라코타 80% + 흰색 20%. 어두운 화면의 작은 오류 글자.
- `--status-error-ink`: 테라코타 70% + 검정 30%. 크림 팝업의 강조 글자·흰 글자를 받치는 위험 작업 버튼·알림 배지.
- `--status-error-hover`: 테라코타 80% + 검정 20%. 위험 작업 버튼 호버.
- 비활성은 별도 회색을 추가하지 않고 opacity로 표시한다.

`--bg`, `--surface`, `--text`, `--panel-gray`, `--accent`는 기존 컴포넌트와 연결하는 별칭이며 독립된 원색이 아니다. 설정창의 `--accent`는 선택 회색을 가리킨다.

## 예외와 범위

- `treemapColorScale.ts`, `accentPalette.ts`, `StockBox.tsx`, `SectorBox.tsx`, `OverviewMap.tsx`의 데이터·업종 표시색은 그대로 유지한다. 단, 큰 하락률(20~25%) 끝 포인트에는 스카이 블루 `#38BDF8`을 사용한다. 홈 시장 수치의 빨강·파랑도 데이터색이다.
- 지도 하락 파랑은 인디고 쪽 색조 228°·채도 60%(명도 16·33·46·58 → `#101A41`·`#223687`·`#2F4BBC`·`#546DD4`)다. 상승 빨강은 채도 75% 그대로다. 이전 슬레이트 쪽 파랑은 색조 215°·채도 55%(`#12253F`·`#264C82`·`#356BB6`·`#598ACF`)였다.
- 거래 세션 점은 프리·메인·애프터·종료를 나타내는 데이터 상태색이다. 같은 팔레트를 쓰던 종가·누적·별도 선택 배경은 UI 선택 회색으로 분리했다.
- Google 로고의 브랜드색과 기존 로고 PNG는 통합 대상이 아니다. 로고의 SVG 슬로건 글자는 공통 흰색을 쓴다.
- 캔버스·이미지 데이터 URL처럼 CSS 변수가 전달되지 않는 경계에는 같은 기본색의 실제 HEX를 전달한다. 색상을 추가하는 예외가 아니다.
- 사용하지 않던 `--stock-up`, `--stock-down`, `--negative`와 `.positive`·`.negative` 선언은 제거했다. 지도의 실제 등락률 팔레트와는 무관하다.

실제 화면에는 혼합·투명도·데이터색이 더해진다. 따라서 기본색 14개는 렌더링된 모든 픽셀의 색이 14개라는 뜻이 아니다.
