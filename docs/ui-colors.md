# UI 색상 규칙

## 통합 계획과 적용

1. 지도·그래프의 데이터 색, 강조 색상 선택지, 거래 세션 점, 외부 로고는 분리한다.
2. 사이트 UI의 회색·파랑 계열 중복을 배경·표면·패널·테두리·글자 역할에 맞춰 합친다.
3. 오류 표시는 테라코타, 주의 팝업과 위험 확인 버튼은 기존 +8% 빨강, 관리자 전용 표시는 골드를 쓴다. 성공은 메인 청록을 공유한다.
4. 호버·선택·비활성은 기본색의 혼합·투명도·opacity로 표현한다.
5. 기본색 수, 데이터 팔레트 보존, 주요 글자 대비, 린트·빌드, 실제 화면을 확인한다.

## 색의 세 갈래

색은 세 갈래로 나눠 관리한다. 같은 일을 하는 색이 두 갈래에 걸치지 않게 한다.

### 1. 기본 원색 12개

원색 정의는 `src/index.css`의 `:root`에 모은다. Tailwind에서는 같은 파일의 `@theme inline`에 등록한 역할 이름을 사용한다.

| 구분 | 변수 | HEX | 역할 |
|---|---|---|---|
| 브랜드 | `--brand` | `#12B8A6` | 선택 메뉴·강조·아이콘 |
| 브랜드 | `--brand-surface` | `#20635D` | 주요 버튼·배지 배경 |
| 서브 | `--sub-yellow` | `#E6D04A` | 프리 마켓 점·안내 배지(50%를 설정창 회색에 섞음) |
| 서브 | `--sub-purple` | `#B39DDB` | 애프터 마켓 점·종가/누적/별도 토글 선택 칸 |
| 서브 | `--sub-gold` | `#D6A45A` | 관리자 전용 표시 색(`--admin-only`의 원색) |
| 팝업 | `--ui-popup` | `#FFF8E7` | 크림 바탕 |
| 상태 | `--status-error` | `#C47B5A` | 오류 상태의 테라코타 원색 |
| 검정 계열 | `--ui-background` | `#0A0A0A` | 메인 영역·어두운 오버레이·팝업 글자 |
| 검정 계열 | `--ui-surface` | `#1A1A1A` | 상단 영역·표면·밝은 선택 영역의 글자 |
| 검정 계열 | `--ui-panel` | `#2A2A2A` | 설정창·필터·표 헤더·입력창 |
| 흰 계열 | `--ui-muted` | `#9CA3AF` | 보조 글자 |
| 흰 계열 | `--ui-white` | `#FFFFFF` | 흰 글자·아이콘·혼합 기준 |

성공 메시지의 `--status-success`는 `--brand`의 별칭이다. 별도 원색을 정의하지 않는다.

### 2. 무채색 단계 (검정·흰 계열 — 따로 관리)

검정 계열은 위 원색 세 개(`background`·`surface`·`panel`, 간격 16)이고, 흰 계열은 설정창 회색(`panel`)에 흰색을 **퍼센트 단계로 섞어서** 만든다. 이 갈래의 색은 전부 이 표에 있는 값뿐이다. 다른 이름이 필요하면 별칭으로만 둔다.

| 변수 | 흰색 비율 | HEX(약) | 역할 |
|---|---|---|---|
| `--ui-control` | 20 | `#555555` | 버튼·칸 기본, 기간 띠, 테두리·비활성 트랙 |
| `--ui-control-hover` | 35 | `#757575` | 마우스 올림 |
| `--ui-text` | 90 | `#EAEAEA` | 본문 글자, 선택된 회색 칸 |

별칭: `--ui-border`, `--ui-popup-border` = `--ui-control` / `--ui-selection` = `--ui-text`.

### 3. 브랜드·상태·관리자 파생색 (섞어서 만든 색 — 4개)

- `--brand-surface-hover`: 서브 80% + 메인 20%. 청록 버튼 올림.
- `--status-error-ink`: 테라코타 65% + 검정 35%. 오류 버튼의 진한 바탕.
- `--status-error-text`: 테라코타 80% + 흰색 20%. 어두운 화면의 작은 오류 글자.
- `--admin-only-hover`: 관리자 골드 65% + 흰색 35%. 관리자 버튼·메뉴의 올림 색.

별칭: `--brand-surface-dark` = `--brand-surface` / `--status-error-hover` = `--status-error`(진한 바탕에서 원색으로 밝아짐).

비활성은 별도 회색을 추가하지 않고 opacity로 표시한다.

설정창 선택형 항목의 기본 상태는 **미선택 회색 → 호버 흰색 → 선택 청록색**이다. 미선택 칸은 `--ui-control`, 호버 칸은 `--ui-control-hover`, 선택 칸은 역할에 따라 `--brand`(선택 탭·아이콘) 또는 `--brand-surface`(버튼·토글 배경)를 쓴다. 선택된 버튼에는 호버를 겹치지 않고, 선택 불가 상태는 opacity로 흐리게 표시한다. 레일형 단계 선택은 선택 위치를 청록 손잡이로 나타내며, 단계 행은 회색 계열을 유지한다. 실제 색상 견본은 각 견본 색과 선택 체크를 유지한다.

`--bg`, `--surface`, `--text`, `--panel-gray`, `--accent`는 기존 컴포넌트와 연결하는 별칭이며 독립된 원색이 아니다. 설정창의 `--accent`는 선택 회색을 가리킨다.

## 퍼센트 단계

섞는 비율과 투명도는 **10 / 20 / 35 / 50 / 70 / 85** 여섯 단계만 쓴다(`bg-ui-white/20`, `color-mix(… 35%, …)`, `opacity-35`처럼). 위에 정의한 고정 파생색의 혼합비는 예외다. 80%·90% opacity/alpha는 85%로 합치고, 그 외 중간 값(12·15·25·28·30·40·45·55·58·60·75·78 등)은 가장 가까운 단계로 합친다. 15% 선택 행 강조는 20%로 맞춘다. 위 단계는 다음 뜻으로 쓴다.

| 단계 | 뜻 | 예 |
|---|---|---|
| 10 | 아주 옅은 선·바탕 | 구분선, 스크롤 트랙, 옅은 호버 |
| 20 | 기본 상태 | `--ui-control`(패널 80 + 흰 20), 테두리, 청록 칸 바탕 |
| 35 | 올림·선택·비활성 | `--ui-control-hover`, 청록 선택 바탕, `opacity-35` |
| 50 | 절반 | 안내 배지(옐로 50), 팝업 테두리, 청록 외곽선 |
| 70 | 강한 덮개·혼합 테두리 | 어두운 오버레이, 글자 흐리게, 종목 끌기 복제본, 지도 셀 테두리(기본색 70 + 흰색 30), 그림자 |
| 85 | 거의 불투명한 표시 | 가독성이 필요한 배너 글자, 강조 막대, 브랜드 버튼 호버 |

## 예외와 범위

- `heatmapColorScale.ts`, `accentPalette.ts`, `StockBox.tsx`, `SectorBox.tsx`, `OverviewMap.tsx`의 데이터·업종 표시색은 그대로 유지한다. 단, 상승·하락 모두 포인트 색을 쓰지 않는다(하락 스카이·상승 자홍 모두 뺐다). 홈 시장 수치의 빨강·파랑도 데이터색이다.
- 지도 등락 색은 하락 인디고(색조 228°·채도 60%)와 상승 브릭 레드(색조 0°·채도 60%)이고, 명도는 구간 순서대로 16·33·46·64다. 구간은 2/5/8/15%이고 15%를 넘으면 가장 진한 단계 색으로 고정한다(코드: `heatmapColorScale.ts`의 `DEFAULT_MINUS_THRESHOLDS`·`DEFAULT_PLUS_THRESHOLDS`). 이름은 문서에서 부르기 위해 붙인 것이다.

  | 구간 | 하락 이름 | 하락 HEX | 상승 이름 | 상승 HEX |
  |---|---|---|---|---|
  | 0% | 버튼·테두리 회색 | `#555555` | 버튼·테두리 회색 | `#555555` |
  | 2% | 미드나잇 네이비 | `#101A41` | 옥스블러드 | `#411010` |
  | 5% | 인디고 | `#223687` | 브릭 레드 | `#872222` |
  | 8% | 로열 블루 | `#2F4BBC` | 레드 | `#BC2F2F` |
  | 15% | 콘플라워 블루 | `#6C82DA` | 코랄 레드 | `#DA6C6C` |

  이전 슬레이트 쪽 파랑은 색조 215°·채도 55%(`#12253F`·`#264C82`·`#356BB6`·`#598ACF`)였다.

- 주의 팝업의 배지와 확인 버튼, 업종 초기화·배너 종료·삭제·회원 탈퇴 버튼, 업종 삭제 아이콘은 등락률 범례의 기존 +8% 빨강(`#BC2F2F`)을 재사용한다. 이 용도에 새 색상 토큰은 만들지 않는다. 정보 배지·닫기 버튼은 기존 중립 회색, 확인 배지·버튼은 기존 서브색을 쓴다.
- 거래 세션 점은 프리·메인·애프터·종료를 나타내는 데이터 상태색이다. 같은 팔레트를 쓰던 종가·누적·별도 선택 배경은 UI 선택 회색으로 분리했다.
- 공지 배너는 메시지 팝업과 같은 크림색(`--ui-popup`) 배경과 어두운 글자를 쓴다. 공지 종류 배지와 배너 안의 공지 배지는 메시지 팝업의 정보 배지와 같은 중립 회색(`--ui-control`)과 흰 글자를 쓴다. 광고 종류 배지는 관리자 골드를 유지한다.
- 원형 간격 다이얼은 조작할 수 있는 바늘과 중심점만 브랜드 초록(`--brand`)으로 표시한다. 선택 부채꼴과 현재 간격 값 배지는 중립 회색을 써 초록색이 조작 요소임을 알린다.
- Google 로고의 브랜드색과 기존 로고 PNG는 통합 대상이 아니다. 로고의 SVG 슬로건 글자는 공통 흰색을 쓴다.
- 캔버스·이미지 데이터 URL처럼 CSS 변수가 전달되지 않는 경계에는 같은 기본색의 실제 HEX를 전달한다. 색상을 추가하는 예외가 아니다.
- 사용하지 않던 `--stock-up`, `--stock-down`, `--negative`와 `.positive`·`.negative` 선언은 제거했다. 지도의 실제 등락률 팔레트와는 무관하다.

실제 화면에는 혼합·투명도·데이터색이 더해진다. 따라서 기본 원색 12개는 렌더링된 모든 픽셀의 색이 12개라는 뜻이 아니다.
