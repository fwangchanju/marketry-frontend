## 해석 범위

이 값은 **로그인된 기존 Chrome 세션의 따뜻한 새로고침 시간**이다. 처음 방문하는 비로그인 사용자의 체감 속도, 동시 사용자 부하, 모바일 접속 속도를 뜻하지 않는다. 텔레그램 발송 시간도 포함하지 않는다.

비로그인 상태의 `/home`과 `/api/summary` 요청은 Cloudflare Access 로그인 주소로 `302` 이동했다. `curl -L`로 따라가면 로그인 HTML이 `200`으로 돌아와 API 응답처럼 보이므로, 해당 요청의 시간은 기준값에서 제외했다. 일반 방문자에게 오픈할 때는 Access 정책을 확인하고, 공개 접근 정책이 바뀌면 새 기준을 측정해야 한다.
