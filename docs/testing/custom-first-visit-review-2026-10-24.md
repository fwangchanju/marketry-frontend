# Custom 첫 방문 점검 (2026-10-24)

## 범위

- 로컬 프론트·백엔드에서 시크릿 Chrome의 비로그인 상태와 기존 로그인 계정으로 `/custom/sector`, `/custom/stock` 확인
- 비로그인: MARKETRY·거래소 읽기 전용 표, `내 분류` 선택 시 로그인 안내, 종목 검색의 결과 없음 표시 확인
- 기존 로그인 계정: 내 분류 업종·종목 표 표시 확인. 종목 화면의 Chrome 오류 로그 없음
- 새 빈 계정 생성이나 데이터 변경은 하지 않음. 신규 계정의 빈 상태는 코드 경로만 검토

## 결과

- 확인한 경로에서 화면 중단이나 명백한 기능 오류는 없었음.
- 첫 방문 시 분류 선택의 기본값은 `MARKETRY`다. 로그인한 신규 회원도 `내 분류`를 고르기 전에는 읽기 전용 표를 보므로, 빈 내 분류 안내와 업종 추가 입력칸을 발견하기 어렵다. `내 분류`에 들어가면 업종 추가 → 종목 분류 순서의 안내 창이 표시되고, 업종 추가 입력칸이 강조된다.
- 읽기 전용 종목 표에도 선택 체크박스가 보인다. 선택은 표 내부 표시 기능이지만, 신규 방문자는 선택한 종목을 편집할 수 있다고 예상할 수 있다.
- Custom 탭의 `SECTOR`·`STOCK` 선택지는 데스크톱에서는 마우스를 올리면, 터치에서는 탭을 처음 누르면 열린다. 첫 방문 화면에 이 두 단계의 설명은 없다.

## 오픈 전 개선 후보

1. 로그인한 사용자가 Custom에 처음 들어와 내 분류가 비어 있으면 `내 분류`와 업종 추가 위치를 명확히 안내한다. 다른 페이지와 공유하는 분류 선택 기본값을 바꾸기 전에 영향 범위를 확인한다.
2. 읽기 전용 종목 표의 체크박스 목적을 설명하거나, 편집 기능으로 오해하지 않도록 표시를 조정한다.

## 확인 한계

- 실제 신규 계정의 Google 로그인·최초 업종 생성·종목 배정 저장은 확인하지 않았다.
- 운영 사이트의 비로그인 첫 방문은 Cloudflare Access가 켜져 있어 확인하지 않았다. 이 점검은 로컬 화면 기준이다.
